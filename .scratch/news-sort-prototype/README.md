# 新闻卡片排序原型

一次性原型，用于比较卡片顶部中央拖动手柄的外观，不接入正式新闻接口或账户数据。

从项目根目录运行：

```sh
npm --prefix .scratch/news-sort-prototype run dev
```

打开 `http://127.0.0.1:5197/news?variant=A`。底部切换 A 灵动岛手柄、B 顶部页签、C 中央拖动栏；“状态”查看当前排序与隐藏来源。

鼠标按住手柄移动，手机长按手柄约 200 毫秒后移动；实时预览，松手保存，Escape 取消。不提供键盘排序。

来源设置可切换来源、二次确认后恢复默认顺序、模拟保存失败。正常保存不显示提示，仅保存失败时显示错误。排序仅写入独立原型键 `lifespace.prototype.news-order.v1`，来源开关和模拟故障仅在当前页面生效。示例新闻链接不跳转，刷新不访问外部服务。

确认外观后再按正式开发流程独立实现；原型未提交。
