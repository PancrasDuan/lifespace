# 人生冒险页面展示方案

顶部展示方案已确认；当前仍处于需求与原型讨论，不进入正式开发。奖励与结算规则以 [CONTEXT.md](../../CONTEXT.md#目标规划领域术语) 为准。

## 已确认展示

页面右上角常驻统一“新建”菜单，在冒险概览、主线与支线和成长记录三个视图中均可使用，提供“创建主线／支线”“创建目标”和“创建任务”三个入口。创建主线／支线时选择类型并只创建空容器；创建目标时选择已有主线或空支线作为归属。分组标题、支线列表和底部不重复设置这些创建入口；创建任务时选择所属目标，也可从目标详情进入并预选归属。

从右上角统一入口创建目标或任务时，归属初始为空，不默认选中第一条主线或第一个目标，必须由使用者手动选择。创建目标显示“选择主线或支线”，创建任务显示“选择任务所属的目标”；提示仅作未选择时的占位，展开列表时隐藏且不可选，未选择归属不能提交。

编辑入口位于主线、在用支线标题旁，以及目标行的“更多”菜单和目标详情中。主线、支线可修改名称，目标可修改名称和完成标准。保存后保留原有归属、任务、聚焦状态和成长积累（经验、完成次数、任务月、达标月及长期系数）；容器改名同步更新当前归属文案，不改写已结算历史。修改完成标准不自动确认目标达成，也不重新发奖；取消或关闭编辑不保存。

归档入口位于主线、支线和目标行，确认面板展示关联目标、任务及待结算记录。主线、支线和目标归档后停止推进，取消聚焦，任务、历史记录和已有成长积累保留；未完成任务停止执行，周期任务不再继续安排。已完成任务仍按次日刷新规则结算，已结算记录不重复发奖；归档不代表达成目标，不发放目标奖励。归档内容只读，可从“来源与历史”查看目标、完成标准、原日期下的任务及结算状态，不再编辑、聚焦或添加任务。归档主线仍占最多 5 条主线名额；归档支线释放在用支线名额。取消归档不改变原状态。

完成与结算流程：任务完成和目标达成后先进入待结算，不立即增加正式经验、等级或解锁成就；当天可撤销对应完成记录并更正待结算奖励。撤销目标达成保留原任务完成记录。次日刷新统一处理单次任务、目标及已到期完整任务月三类奖励，范围为前一天及更早未结算记录，更新经验、等级、累计行动、目标达成和成就；已结算记录跳过，不重复发奖。过去记录冻结，撤销不得跨天；归档内容仍遵循只读规则。 目标达成前展示完成标准和奖励预览；结算后提供升级与新成就反馈，并可查看成长记录。原型的“模拟次日结算”用于手动推进日期和查看结算预览，正式规则为次日刷新统一结算。

目标达成后的周期任务：目标达成时，对尚在运行或暂停的周期任务逐项选择继续或结束，不默认代选。选择继续时保留原任务归属、任务月起点、达标月和长期系数，后续行动从“全部任务”或周期管理查看；原目标奖励按达成时的计奖次数和成就系数冻结，后续行动不追加或重算原目标奖励；继续任务的真实单次完成和到期任务月奖励仍分别参加次日统一结算。选择结束时停止后续推进，历史及积累保留，已到期完整任务月仍可结算，未满月不发周期奖励。

三类奖励合并结算：单次任务奖励、目标奖励和已到期完整任务月奖励，在次日刷新时统一处理前一天及更早未结算记录，逐笔保留来源，合并更新主页面经验、等级和成就。周期奖励同步更新所属周期任务的达标月和后续长期系数，不重复增加单次行动次数；已结算任务、目标和任务月记录均跳过，不重复发奖。独立任务月推演仍与主页面隔离，不改变主页面数据，也不将推演奖励导入主页面结算。 主页面提供逐笔结算预览、升级与新成就反馈、周期任务月明细和成长记录。

成长记录与成就详情：每笔经验保留结算时的事项来源、完成／到期日期、结算日期、奖励金额、计算过程和对应任务快照，可附评价与感想。已结算来源和任务快照只读保留，当前事项改名或迁移不改写历史；可另行查看当前目标与任务。成就详情展示解锁条件、当前进度、解锁日期及关联记录；新解锁成就保留当轮进度变化和触发记录，支持查看对应经验明细。未解锁成就展示剩余差额，不填解锁日期。初始历史缺少逐笔来源、任务明细、原始日期或触发记录时明确标注为初始快照或历史汇总，不虚构关联任务、日期或记录，也不将后续新记录当作最初触发来源。

周期任务暂停、恢复与结束：入口在周期任务展开区及任务区“周期管理”，操作前展示对安排、满月日期和长期积累的影响，取消不保存。暂停期间不安排任务，暂停天数不计计划次数，任务月结束日期按暂停天数顺延。恢复后按原重复规则继续安排，不补造暂停期间的完成记录；已有经验、历史、累计达标月和长期系数保留。结束后停止推进和后续安排，任务及历史保留；结束前已到期的完整任务月仍按次日规则结算，未满任务月不发周期奖励、不增加达标月，也不自动触发目标达成奖励。已完成任务仍按次日规则结算，已结算不重复发奖。 状态及操作历史可在周期记录中查看。

修改重复规则：入口为“周期管理 → 修改重复规则”，保存前展示执行日期、计划次数、完成率和奖励预览。周期任务可调整重复频率、执行星期、生效日期和结束日期。新规则从今天或未来指定日期生效，生效前仍按原规则，生效日起更新尚未执行的未来安排与任务月计划次数；按日期分段统计，不改写过去记录、已完成记录或已结算奖励，不重复计奖。任务月起点、累计达标月和长期系数保留，修改本身不重置积累、不立即发奖；后续到期任务月按有效规则和实际完成情况结算。取消或关闭编辑不保存。

任务月结算与长期奖励：周期任务按完整任务月结算，完成率封顶 100%；计划次数大于 0 且满月完成率达到 80%，才增加 1 个达标月，每任务月最多增加 1 个。达标月份累计、不要求连续；每累计 3 个完整达标月，下一任务月起长期系数复利增加 10%（1 → 1.1 → 1.21），新增档位不追溯用于刚结算的任务月。无计划、未满月或未达标不增加达标月，已有积累保留。原型通过独立任务月推演窗口输入模拟汇总，展示完成率、周期奖励、达标月、本月与下月长期系数及逐月结算记录；推演经验、等级投影和长期成就进度只在窗口内变化，不改变主页面日期、任务记录、经验、等级或成就，不与主页面结算重复发奖。 入口为“演示工具 → 独立任务月推演”或预置周期任务中的“推演任务月奖励”；关闭、重置或切换样例会清空该窗口推演。

顶部由两块并列区域和下方一排徽章组成：

- **左侧个人区域**：像素小人作为虚拟个人形象；展示等级、本级经验、距下一级经验和累计经验。经验条采用短、细的紧凑样式，不横跨整个页面。角色图片为原型生成素材，不代表真实外貌。
- **右侧 dashboard**：展示今日完成次数与完成率、累计行动次数、目标达成数量、当前聚焦目标数量（按主线分别统计，每条最多 3 个，不显示全局 x/3 上限）和今日待结算经验。今日完成随当日操作更新；累计统计、等级与正式经验只采用已结算记录，待结算经验独立标注。
- **下方成就横排**：首批 10 个成就使用小 logo／徽章横向排列，区分已解锁与未解锁。悬停显示名称与状态，点击查看解锁条件和关联记录；坚持类同类徽章合并，不重复铺开。屏幕较窄时允许横向滚动。

成长记录页保留完整成就记录、下一个里程碑进度及经验来源。成就横排不改变解锁条件，也不额外加分。本期不加入角色属性。

一次性任务重新安排：从“过去”的未完成一次性任务旁进入，选择今天或未来日期并确认；新安排展示原记录来源。漏做的一次性任务可重新安排到今天或未来日期，保留原未完成记录并关联新的执行安排；不改写过去记录，不通过重新安排补记历史完成。重新安排本身不发奖，只对实际完成计奖，同一行动不重复计奖。

周期任务额外完成：从任务区“周期管理”或周期任务展开区进入“额外完成一次”，确认是另一次真实完整活动后记录。周期任务支持记录当天额外真实完成的一次活动，关联同一周期任务，增加实际完成次数和对应单次待结算经验，不增加计划次数；完成率仍封顶 100%，每个任务月最多增加一个达标月。同一行动不重复记录或计奖。

## 主线、支线与目标结构

- 目标进入所属主线的“调整顺序”模式后，支持拖动手柄和上移／下移按钮，排列顺序表示优先级；排序与聚焦状态独立，调整顺序不自动聚焦或取消聚焦，每条主线最多聚焦 3 个目标的限制保持。
- 使用者可创建自己的主线，最多 5 条；每条主线可创建多个目标，最多同时聚焦 3 个目标。聚焦限制按主线分别计算，不设全局 3 个上限。
- 每条支线最多挂 1 个目标，允许暂时为空，目标下可以安排任务；最多 10 条在用支线，空支线、尚未开始和正在进行的均占名额，已完成或归档的不占名额。达到上限时提示先处理已有支线，不自动完成、归档或转换。
- 支线升级支持两条路径：转为新主线并保留原目标，或将目标移入已有主线。保留原目标及记录，不重复计数或发奖。
- 转为新主线占用 5 条主线的名额；移入已有主线不增加主线数量。主线目标暂不支持降级为支线。
- 升级或迁移时保留原聚焦状态；需要保留聚焦且目标主线已聚焦 3 个目标时，提示使用者先调整再继续，不自动挤掉其他目标，也不自动取消原目标的聚焦。原本未聚焦的目标不会因升级或迁移自动聚焦。
- 升级或迁移成功后，原支线退出在用列表并释放名额，保留目标、记录和可追溯来源，不留下可继续添加目标的空容器。升级为新主线时，原目标成为其第一个目标；移入已有主线时，原支线归档为来源记录。目标、任务、完成标准、历史记录和周期积累保留，任务月、达标月、长期系数不重置，不重复计数或发奖。先校验名额与聚焦条件，失败或取消时原状态保持不变，不提前释放名额；转换后的来源记录仅供回看，不能恢复成支线。

## 已确认的交互组织

- 任务区提供聚焦任务／全部任务和日期范围切换，逐行显示主线或支线与目标名称；Dashboard 明确采用全部可执行目标的计划口径，当前列表显示本筛选范围的计数。
- 目标日常行保留状态、聚焦和“更多”；查看、添加任务、编辑与归档集中在“更多”。排序控件仅在调整顺序模式显示，保持聚焦独立。
- 周期管理属于业务入口，在任务区及对应周期任务展开区可进入；C 地图另提供任务列表切换，使用相同状态筛选。
- 重置、模拟结算、独立推演、样例加载和状态查看集中到折叠的“演示工具”，与业务操作分开。
- 从目标详情进入任务表单，取消或关闭返回原目标；弹窗支持 Escape 关闭并限制键盘焦点。通用计奖说明折叠，当前操作影响与奖励预览保留。
- 保留个人形象、紧凑经验条、Dashboard 和成就横排，压缩介绍留白及重复统计，C 保留原底色并提高辅助文字、边框和按钮可读性。
