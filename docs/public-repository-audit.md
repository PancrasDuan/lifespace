仓库公开会公开源码、可达历史、现有 Issues/PR 和提交元数据。项目域名、Worker/Supabase 项目定位信息、GitHub 用户信息属于已确认的公开范围；这些标识不能代替服务端密钥。

本次未发现真实凭据泄露。扫描覆盖上述范围，不能保证所有未知格式、编码或人工遗漏均被识别。后续提交先扫描密钥，PR 必须通过 `validate`；评审仍需检查敏感日志、附件、公开响应及前端资源。

业务凭据继续保存在忽略的本地配置与 Cloudflare Worker runtime secrets。CI 使用假值完成安全测试，不读取生产凭据、不上传测试报告、轨迹或构建产物。
