# Lifespace 本期需求

## 目标

完成一个供本人使用的每日首页，提供 Google 搜索和时间、天气、任务、日历卡片，支持电脑与手机浏览器查看。四类信息均为只读展示，卡片支持点击交互。

## 页面结构

- 顶部：居中的 `lifeSpace` 艺术字。
- 搜索区：艺术字下方放置 Google 搜索框。
- 卡片区：搜索框下方展示时间、天气、任务和日历卡片。
- 侧边导航：首页、任务管理、个人目标、财务、股票行情；首页为当前页面，其余栏目显示为禁用占位。
- 视觉参考所附 iTab 截图，采用宽搜索框、圆角卡片和统一间距；电脑多列、手机单列。

## 首页功能

| 功能 | 本期要求 |
|---|---|
| 搜索 | 输入关键词，按 Enter 或点击搜索按钮，在新标签页打开 Google 搜索结果 |
| 时间 | 同时显示本地与指定海外时区的日期、星期和当前时间，标注时区；海外时区可配置，各时区独立跨午夜更新 |
| 天气 | 城市、天气、当前温度、今日高低温；来源支持时展示降雨提示 |
| 任务 | 展示未完成的今日计划、今日截止和逾期任务，标注时间 |
| 日历 | 展示当天公历日期、星期、农历日期及黄历宜忌 |
| 卡片交互 | 支持点击，具体动作按卡片确认 |
| 刷新 | 各卡片独立刷新，展示最后成功获取时间 |
| 状态 | 区分加载中、尚未连接、没有内容、获取失败和授权失效 |
| 访问与布局 | 私人访问；电脑多列卡片、手机单列卡片 |

## 展示规则

- 搜索内容经 URL 编码后交给 Google 检索，空关键词保持当前页面。
- 信息卡片标注数据来源与更新时间，提供独立刷新入口；时间卡片按设备时钟持续更新。
- 本地时区默认跟随设备；海外时间按指定地区时区换算，自动适配夏令时。
- 任务按来源字段分组，同一任务展示一次；计划日期缺失时隐藏“今日计划”分组。
- 日历独立展示日期与黄历，按本地日期匹配内容，跨午夜更新。
- 任一卡片失败时，其他卡片保持可用；旧数据标注为上次结果。
- 默认按本人使用、每类数据一个来源设计；任务和日历的“今天”按本地时区判断。

## 制作流程

1. **确定来源**：选择天气、任务和黄历来源，确认读取字段与接入方式。
2. **设计首页**：完成艺术字、搜索框和卡片布局，确认卡片点击行为，覆盖电脑与手机及各数据状态。
3. **确定技术**：验证接口与访问条件，选定技术栈及 Cloudflare 或腾讯云部署方案。
4. **开发接入**：完成页面、Google 搜索、卡片交互、访问控制、数据读取和刷新。
5. **验收发布**：核对数据与交互，完成常用设备测试和上线验证。

当前待定：指定海外时区、卡片点击行为、天气城市与供应商、任务和黄历来源、登录方式、技术栈及部署方案。

## 验收标准

- 页面按艺术字、搜索框、卡片区的顺序呈现，Google 搜索可通过 Enter 和按钮触发。
- 卡片点击响应符合各卡片定义。
- 本地与海外时间、日期显示正确，跨日与夏令时处理准确。
- 天气、任务与来源一致；日历的公历、农历及黄历信息对应当天。
- 四类信息均为只读展示，刷新后反映来源的最新数据。
- 空数据与获取失败区分清楚，卡片异常互不影响。
- 私人数据仅本人可访问，电脑与手机布局正常。
- 导航占位保持禁用状态。
