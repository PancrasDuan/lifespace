# LifeSpace 本期需求

状态：当前有效需求；人生冒险规格更新于2026年10月19日，交付验收状态见对应覆盖记录。

## 目标

提供首页、新闻与人生冒险三个业务页面。每日首页提供 Google 搜索和时间、天气、任务、日历、DNSHE 域名卡片，支持电脑与手机浏览器查看。首页信息为只读展示，卡片支持点击交互；人生冒险支持个人规划与成长数据写入。

全站业务界面与 API 采用邮箱白名单及 Supabase Auth 准入，获准使用者共用现有首页展示数据，人生冒险数据按账户隔离。注册、登录、恢复、会话撤销和 B 页面验收见 [认证规格 #33](https://github.com/PancrasDuan/lifespace/issues/33)。邮件渠道接入另行验收。

## 页面结构

- 顶部：居中的 `LifeSpace` 艺术字。
- 搜索区：艺术字下方放置 Google 搜索框。
- 卡片区：搜索框下方展示时间、天气、任务和日历卡片；下方增加一张横向 DNSHE 域名卡片，手机上按单列排列。
- 侧边导航：首页、新闻与人生冒险可用，当前页高亮；任务管理、个人目标、财务、股票行情为禁用占位。新闻页的范围和验收标准见 [新闻页规格 #6](https://github.com/PancrasDuan/lifespace/issues/6)。
- 使用已确认的浅色布局：薄荷白背景、白色圆角卡片和深绿色文字；电脑多列、手机单列。艺术字下只显示“把今天放在眼前”。

## 首页功能

| 功能 | 本期要求 |
|---|---|
| 搜索 | 输入关键词，按 Enter 或点击搜索按钮，在新标签页打开 Google 搜索结果 |
| 时间 | 本地与海外时间横向排列，本地时间较大，日期在时间上方，地点后同一行显示 UTC 时差；各列对齐，海外时区可配置，独立跨午夜更新 |
| 天气 | 使用 Open-Meteo 展示独立天气城市的天气、当前温度、今日高低温及降雨提示，标注数据来源 |
| 任务 | 读取 Supabase 项目 `personal_os` 的 `public.tasks` 中当天的 `todo` 任务，首页显示总数和最多三条，详情查看全部；展示标题、计划时间及可用的截止时间 |
| 日历 | 使用 `tyme4ts` 本地生成当天公历日期、星期、农历日期及黄历宜忌 |
| DNSHE | 显示账户全部域名的数量、名称、状态和剩余天数，详情显示全部到期日期；提供独立登录页跳转入口（`https://my.dnshe.com/clientarea.php`） |
| 卡片交互 | 卡片点击后展开只读详情；天气详情包含当前指标、未来 24 小时趋势、七日预报和空气质量，可搜索城市、切回当前位置与选择预报日期；任务详情展示标题和时间信息 |
| 刷新 | 各卡片独立刷新，展示最后成功获取时间 |
| 状态 | 区分加载中、尚未配置、没有内容、获取失败和数据源连接失效 |
| 设置 | 配置自动定位或手动地区及海外时区，点击保存后保存在当前浏览器 |
| 访问与布局 | 登录并通过白名单后才可访问首页业务界面和任务数据；电脑多列卡片、手机单列卡片 |

## 展示规则

- 搜索内容经 URL 编码后交给 Google 检索，空关键词保持当前页面。
- 信息卡片标注数据来源与更新时间，提供独立刷新入口；时间卡片按设备时钟持续更新。
- 有效地区按手动地区、自动定位地区、默认北京的优先级确定。本地时间、日历和今日待办统一使用有效地区时区；卡片更新时间、服务状态检查时间和域名剩余天数继续使用设备时区。
- 自动模式每次进入首页定位一次，等待期间使用北京；8 秒截止包含授权等待，失败回退北京。地区搜索使用下拉列表，选择城市即设为手动地区，选择“使用当前位置”并保存后重新定位或恢复自动模式，迟到结果不得覆盖新尝试或手动选择。
- 自动坐标保留两位小数，仅留在页面内存；时区在浏览器本地解析，天气使用单独选择的城市，由本站 Worker 请求 Open-Meteo。新版首页设置仅重置一次，不影响新闻设置；详见 [位置获取规格 #19](https://github.com/PancrasDuan/lifespace/issues/19)。
- 海外时间按指定地区时区换算，自动适配夏令时和非整数小时偏移。摘要最多两个海外时区，额外时区提示上方显示分割线。
- 任务按本地当天的 `planned_at` 筛选，保留 `status=todo` 且 `is_deleted=false` 的记录，同一任务展示一次。
- 任务默认按计划时间升序排列；时间字段按 Unix 秒读取，已通过真实只读接口联调核验。
- 日历独立展示日期与黄历，按本地日期匹配内容，跨午夜更新。
- DNSHE 查询账户内全部注册域名；首页显示总数及最多三条，详情完整展示名称、状态、到期日期和剩余天数。永久有效与到期日期未知分别显示；剩余天数按本地日历日期计算。凭据未配置时登录页入口仍可使用。
- 静态网页外壳可公开加载，业务数据须通过认证与白名单；DNSHE 凭据仅在服务端使用，业务响应仅包含已确认的展示字段，前端资源、错误响应、日志及 Git 均不得泄露密钥。
- 天气一级与二级卡片共用独立保存的天气城市，默认北京；候选列表始终提供“使用当前位置”，可从任意手动城市切回独立自动定位。定位模式保存在浏览器，自动坐标保留两位小数用于天气请求且不写入存储，每次进入页面重新定位，失败或超时明确回退北京并可重试。原手动城市配置继续保留；在二级卡片切换后同时更新两张天气卡片，不受首页设置影响，也不影响其他模块。天气的“今天”按天气城市时区判断，预报与摘要共用同一查询快照；切城或跨日不混用旧数据。
- 天气详情沿用薄荷白与深绿色，支持宽窗、关闭与焦点恢复；手机横向浏览预报。展示体感、湿度、风、海平面气压、当前时段降水、日出日落、24 小时温度趋势与七日高低温和降雨概率；缺失指标明确显示。
- 空气质量独立加载，展示模型数据时间、美制 AQI、PM2.5 和 PM10，标注 Open-Meteo 与 CAMS 来源及口径；失败不阻断天气，旧数据明确标注。
- 服务状态卡片汇总 OpenAI、xAI、Resend、GitHub、Cloudflare、Supabase、Notion、Tailscale 与腾讯云，详情按提供方分组；Resend 仅 SMTP、General API、Single Email 影响汇总，详情展示全部组件及当前事件。每小时、打开页面、重新聚焦及手动刷新时获取，后台不定时刷新；失败显示未知，旧结果标注成功时间，异常优先于未知、未知优先于正常。
- 服务状态一级右上角提供“设置服务”，勾选即时控制一级与二级，默认只选 OpenAI、xAI；整体状态仅汇总展示服务。选择保存在当前浏览器，允许全部取消并刷新保留空态；配置损坏回退默认，未知来源忽略，存储失败提示未保存且本页仍生效。
- 服务状态一级卡片采用单列，一个系统一行，仅显示系统名称与当前状态，正常系统保持可见；异常事件、子服务与历史结果放在二级详情。
- 服务状态二级详情为各提供方设置独立边框、标识、状态和来源；子服务默认收起，折叠入口显示数量与异常提示，分组可分别展开；异常事件保留在外层，电脑和手机无横向溢出。
- 任一卡片失败时，其他卡片保持可用；旧数据标注为上次结果。
- 默认按本人使用、每类数据一个来源设计；任务和日历的“今天”按本地时区判断。

## 技术与接入

- 网页：React + TypeScript + Vite；TanStack Query 管理数据获取、刷新与卡片状态。
- 服务端：Cloudflare Worker + Hono，提供 `/api/tasks/today`、`/api/weather` 等 HTTP 接口。
- 页面通过集中封装的请求模块访问接口，服务端统一返回卡片数据；后续后端服务沿用接口契约。
- 任务及 DNSHE 凭据保存在服务端，分别读取现有 Supabase 任务库及 DNSHE 官方只读 API；时间与 `tyme4ts` 黄历在浏览器计算。
- 部署：Cloudflare Workers Static Assets 托管网页，同项目 Worker 承载 API。

## 人生冒险

本期增加 `/adventure`，保留像素个人形象、紧凑经验条、右侧统计和成就横排。以下是 2026-10-20 已同步目标领域、待实现的新规范；本次只更新文档，现有代码、原型和旧验证结果不代表已符合新规则。完整规则见 [当前规格](adventure/spec.md)，实现证据范围见 [覆盖记录](adventure/coverage.md)。

- 规划：最多 5 条在用普通主线，结束释放名额；固定独立区承载数量不限的独立目标及独立任务，不占名额、不能结束；普通主线只通过目标挂任务。目标名称和完成标准必填、归属手选，进行中可修改，修改不触发达成；第一版无目标删除、草稿或多阶段。
- 执行：支持一次性任务、周期规则和不计奖清单；当天完成与撤销、当天或未来编辑、过去冻结。漏做的一次性任务重新安排保留来源；周期额外完成不增加计划次数。
- 周期：支持暂停顺延、恢复保留积累、单独结束周期后的完整月资格保留既有独立规则，目标终态后的待结算奖励留待后续讨论，以及今天或未来生效的重复规则修改；排期与月统计不受原型28天预览限制。
- 奖励：单次完成+1 XP；目标奖励按达成时冻结的真实次数和1／2／3系数计算。任务月完成率封顶100%，基数10 XP、80%达标，每累计3个达标月从下一任务月复利加成10%，每笔最终向下取整。
- 聚焦与历史：聚焦仅适用于进行中目标，只影响排序和所属任务筛选；每普通主线最多 3 个、独立目标共用 3 个，聚焦在前且组内保留手动顺序，终态自动取消。终态默认隐藏、手动显示，只读详情与已结束主线入口保留；其他展示细节不在本轮扩展。
- 生命周期与迁移：目标只有进行中、已达成终态和未达成而结束终态；仅手动确认目标或手动结束所属主线改变，任务全完成或全迁出不自动改变。无任务或有未完成任务均可按标准达成；达成即停止所有下属任务，继续任务先迁出。终态不可撤销、恢复、修改或迁移，下属任务及相关完成记录只读。目标跨主线或独立区迁移时任务随行，保留聚焦、先验名额、落位目的同类组末尾；失败或取消不变，历史归属不改写。
- 成长：本轮不展开奖励计算、记录删除和到期结算。仅未被终态锁定的当天任务完成可取消，目标达成和主线结束不可取消；取消任务完成不追加负数冲正，奖励记录处理细节后续讨论。每次完成保存当时主线、目标、任务身份及日期，独立任务无所属目标。
- 隔离与日期：真实账户独立持久化，固定 Asia/Shanghai 划分当天。GET 只读取／初始化，POST `refresh`追赶已到期完整任务月；任务与目标奖励随对应业务命令原子提交。客户端不能指定 owner、经验或结算日期。
- 验收：目标结构、必填、手动状态、聚焦、终态传播及只读、迁移与历史归属、无目标删除和只读查看需按新规则重新验证；既有数据库权限／CAS 证据保留，不代表新领域规则已通过。代码及原型待实现，本次不操作数据或发布。

全站夜间主题、角色属性、原型模拟数据和独立认证扩展不在本期。

## 制作流程

1. **设计首页**：制作电脑与手机原型，核对艺术字、搜索框、卡片及详情布局。
2. **验证接入**：核验 Supabase 读取、任务时间字段单位及 Open-Meteo 城市与天气接口。
3. **开发接入**：完成页面、搜索、卡片交互、设置、数据读取和刷新。
4. **验收发布**：按验收标准核对功能，验证常用网络及设备上的访问体验，再发布到 Cloudflare。

## 验收标准

- 页面按艺术字、搜索框、卡片区的顺序呈现，Google 搜索可通过 Enter 和按钮触发。
- 卡片点击响应符合各卡片定义。
- 本地与海外时间、日期显示正确，跨日与夏令时处理准确。
- 天气、任务与来源一致；本地时间、任务和日历对应有效地区当天，天气对应独立天气城市当天。
- 首页信息只读展示，刷新后反映来源的最新数据；DNSHE 刷新失败保留上次结果，分页读取不遗漏或重复，响应仅包含展示字段且不泄露凭据。
- 空数据与获取失败区分清楚，卡片异常互不影响。
- 未登录或未获准账户不能读取业务数据；首页地区、天气城市和海外时区分别在当前浏览器保存，电脑与手机布局正常。
- 导航占位保持禁用状态。
