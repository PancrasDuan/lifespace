# LifeSpace 认证界面原型

状态：B 布局已通过用户评审。确认日期：2026-10-11。认证页采用左右分栏，手机收敛为紧凑品牌标题；首页沿用现有布局，头像退出菜单及主要状态按原型落实。

这是独立的本地原型，不接真实 Supabase 或业务 API，不保存输入，不进入生产构建。

## 打开

项目根目录运行：

```bash
node docs/poc/auth-prototype/serve.mjs
```

打开 `http://127.0.0.1:8793/prototype/auth?variant=A`。Ctrl+C 停止。

完整页面与异常图集：`http://127.0.0.1:8793/prototype/auth/gallery`。包含三种布局的电脑／手机对照，以及主要页面和异常状态的截图；点击图片可查看原始尺寸。

- A：品牌与单一卡片居中。
- B：品牌故事与表单左右分栏，手机收敛为紧凑标题。
- C：轻量顶栏与横向面板，登录采用邮箱、密码两个步骤。

底部原型面板可切换布局、页面和模拟状态，填入演示内容、模拟邮件回跳；左右方向键也可切换布局，输入时不拦截。可收起面板。页面和布局可通过 URL 分享，表单与模拟会话仅存在内存。

## 评审

覆盖登录、注册、验证邮箱、忘记密码、邮件发送提示、重置密码、恢复成功、无资格、登录成功入口与每日首页预览。检查电脑、手机布局，以及字段校验、密码显示与隐藏图标、登录成功后进入首页、加载、密码错误、未验证邮箱、白名单拒绝、链接过期、发送限频、会话撤销、服务故障和“密码已更新、撤销待完成”。

原型的密码最少 8 位、重发等待 30 秒仅为交互演示参数；接入时按已确认的 Supabase 配置实现。C 的分步登录是供选择的布局方案，不代表最终页面流程已改变。

当前已确定界面方案，下一阶段为规格化与任务拆分。原型作为界面依据保留，正式实现按项目结构重新编写。未提交、部署或修改真实账户配置。

本轮已生成 40 个页面与状态截图，完成 17 项原型操作检查，未观察到脚本错误或外部网络请求。检查记录见 [preview-check.json](previews/preview-check.json)。这仅验证模拟界面，不代表真实认证已验收。

首页预览复用现有 Home / AppLayout 的布局与首页 CSS，信息全部替换为演示数据，未挂载真实 Home 组件或调用其接口。卡片详情、新闻导航和搜索服务不在本次认证原型中实现。

所有页面右上角显示头像，点击可打开账户菜单；已登录时可退出并返回登录页，未登录时退出项置灰。点击外部区域或按 Escape 关闭菜单。
