# 一次性任务验收

2026-10-21，Issue #55 本地收尾，分支 `codex/53-adventure`，本轮基线 `b7373a1`。本轮仅使用临时隔离数据库，未读取或修改现有 Supabase 验收库、验收账户；未推送、合并、部署或关闭 Issue。

## 当前模型

- 保持 Worker → Supabase PostgREST → PostgreSQL RPC。单次函数调用内完成账户锁、版本检查、请求幂等、当前任务、事件、账户经验及回执写入；失败全部回滚。Worker 仅负责身份、输入／响应契约及 HTTP 错误映射。
- 完成只新增一条 `task_completed`，冻结 `amount`、`calculation` 和发生时内容／归属快照。新完成奖励 1 点，历史读取不按当前规则重算。
- 取消按 `completionId` 逻辑失效指定完成事件，扣除其冻结金额，行动数、等级和成就同步回退；保留完成与取消事件，不追加负数奖励。重做创建新事件；原 requestId 跨日、取消或重做后仍只返回原回执。
- 保留每任务最多一条有效完成、每账户请求 ID 唯一及每目标只达成一次的索引；删除独立奖励事件种类、引用列和索引。账户 total_xp 与有效完成／达成事件的冻结金额核对。
- 查询、取消预览和完成／取消回执返回事件冻结的 `reward`；任务卡展示冻结金额。取消预览返回原完成奖励及成长前后结果，提交仍核对预览版本。
- 目标达成和完整成长流水页尚未开放。本轮仅更新达成事件、冻结奖励共享契约及 #59／#62 的本地验收预期，未新增目标达成命令。

## 复跑与隔离预览

```sh
npm run test:database -- --browser
```

需本机 PostgreSQL 与 PostgREST 可执行文件；通过 `POSTGRES_BIN` 指定 initdb／pg_ctl 目录，`POSTGREST_BIN` 指定 PostgREST，动态库可用 `POSTGRES_LIB` 指定。脚本新建随机临时目录和本机端口，禁止沿用外部 PG 连接环境，结束后停止服务并清理。已有 `pg@8.23.1` 仅用于开发测试编排，未引入 Worker 或浏览器运行时。

隔离浏览器截图为 `.cache/adventure55-native-1440.png`、`.cache/adventure55-native-390.png`。当前分支另提供 `http://127.0.0.1:5182/adventure` 预览，已打开并核对虚构任务的“本次奖励 1 点经验”、总经验和行动数；仅连接本轮新建临时数据库，使用明确标注的测试身份。预览保留运行供查看，临时数据不写入现有账户。
