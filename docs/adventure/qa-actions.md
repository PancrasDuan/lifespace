2026-10-21，Issue #55 本地实现及隔离验收完成，分支 `codex/53-adventure`，本轮基线 `032efea`。现有 Supabase 验收库尚未同步函数，不代表该库、用户账户或生产部署已验收。本轮不合并 main、不发布、不关闭远端 Issue。

## 已交付范围

- 顶部新建一次性任务，或从目标详情创建所属任务；名称、执行日及目标／独立归属明确选择，说明可空。目标候选沿服务端分页加载，独立任务复用隐藏 inbox，不增加真实目标数。
- 待完成任务可编辑名称和说明；今天／未来／过去由后端统一查询，逾期仍待完成，未来不能提前完成、过去不能补写完成。
- 完成同时保存任务状态、完成事件、1 点奖励、账户经验、版本及稳定回执；反馈直接展示后端经验、等级和成就结果。
- 取消先展示服务端计算的经验、等级、行动数及成就前后结果，确认时提交预览版本和具体完成事件 ID。完成与奖励同事务逻辑失效；重做生成新的完成关联，旧请求不影响新结果。
- 当前及完成发生时的目标／主线终态均锁定取消；过去完成冻结。历史内容和归属快照保留，不追加负数奖励。
- 沿用全局 toast、原封套安全重试、成功后查询失败只重读、409 重读确认，以及账户切换／倒序响应保护。取消预览过期后必须重新预览。

聚焦、排序、任务进度、改期、迁移、结束、目标达成及完整成长页继续由对应后续任务交付。

## 复跑与本机预览

新增 `pg@8.23.1` 仅作开发依赖。验收入口同时覆盖正常退出与 SIGINT／SIGTERM 中断清理；本轮真实进程探针先复现 SIGTERM 绕过清理，再验证两种信号均停止子进程、数据库并移除自己的临时目录。安装 PostgreSQL 与 PostgREST 可执行文件后运行：

```sh
npm run test:database -- --browser
```

可通过 `POSTGRES_BIN` 指定 initdb／pg_ctl 所在目录、`POSTGREST_BIN` 指定 PostgREST 文件；非系统动态库可用 `POSTGRES_LIB` 指定。脚本在自己的临时目录启动只监听 127.0.0.1 的数据库，使用测试角色、随机 owner 和受控身份，最后停止服务并清理。未显式启动时，默认测试明确跳过这些数据库场景。

浏览器回归截图生成于 `.cache/adventure55-native-1440.png` 与 `.cache/adventure55-native-390.png`。本轮另启动 `http://127.0.0.1:5180/adventure` 隔离预览，使用独立临时 PostgreSQL／PostgREST 与标注的测试身份；已实际打开并核对示例任务完成的 1 点经验及取消预览。预览数据不保存到用户账户，停止预览后丢弃。
