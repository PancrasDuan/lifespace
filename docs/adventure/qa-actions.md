## 当前模型

- 任务归属留空默认独立任务；页面只显示“默认独立任务”和真实目标选项，不提供单独的独立任务选项。空字符串由 Worker 契约和 SQL 统一解释，独立任务复用唯一 inbox。
- 保持 Worker → Supabase PostgREST → PostgreSQL RPC。单次函数调用内完成账户锁、版本检查、请求幂等、当前任务、事件、账户经验及回执写入；失败全部回滚。Worker 仅负责身份、输入／响应契约及 HTTP 错误映射。
- 完成只新增一条 `task_completed`，冻结 `amount`、`calculation` 和发生时内容／归属快照。新完成奖励 1 点，历史读取不按当前规则重算。
- 取消按 `completionId` 逻辑失效指定完成事件，扣除其冻结金额，行动数、等级和成就同步回退；保留完成与取消事件，不追加负数奖励。重做创建新事件；原 requestId 跨日、取消或重做后仍只返回原回执。
- 保留每任务最多一条有效完成、每账户请求 ID 唯一及每目标只达成一次的索引；删除独立奖励事件种类、引用列和索引。账户 total_xp 与有效完成／达成事件的冻结金额核对。
- 查询、取消预览和完成／取消回执返回事件冻结的 `reward`；任务卡展示冻结金额。取消预览返回原完成奖励及成长前后结果，提交仍核对预览版本。
- 目标达成和完整成长流水页尚未开放。本轮仅更新达成事件、冻结奖励共享契约及 #59／#62 的本地验收预期，未新增目标达成命令。
