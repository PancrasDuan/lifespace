# 人生冒险模块规格

状态：2026-10-20 已同步本轮目标领域的当前有效需求，对应 [父规格 #53](https://github.com/PancrasDuan/lifespace/issues/53)。本次仅更新规范，不启动实现。现有功能分支和原型尚未同步主线结束、独立目标与实时奖励规则；已有测试、评审和覆盖记录不证明这些新规则已实现。目标领域以本版为准，奖励结算机制暂不展开；相关待定项集中列在文末。

## 目标与页面

帮助使用者组织长期方向、阶段结果和当天行动，通过经验、等级、成就回看成长。在首页与新闻并列提供人生冒险页面，包含冒险概览、主线与目标管理、成长记录；保留像素个人形象、紧凑经验条、右侧 dashboard 与成就横排。

## 用户故事

1. 创建自定义主线，最多 5 条在用主线；结束后释放名额，历史不占在用名额。
2. 独立区为固定存在的系统特殊主线，不占普通主线名额、不能结束；承载数量不限的独立目标及不依附目标的独立任务，界面仍使用独立目标／独立任务，不新增支线容器。
3. 普通主线先创建空容器，只通过目标承载任务，不能直接挂任务；任务属于目标或独立区。
4. 统一新建入口提供主线、目标、任务；创建目标必填名称和完成标准，手动选择独立或在用普通主线；任务明确选择目标或独立身份，不默认归属，提示仅为不可选占位。
5. 进行中目标可改名称和完成标准，修改不触发达成；取消不保存，关联与积累保留。第一版不提供删除目标，也不引入草稿或多阶段目标。
6. 目标支持手动排序；同一归属内聚焦目标在前、未聚焦目标在后，两组内部沿用手动顺序，调整顺序不自动改变聚焦。
7. 聚焦只适用于进行中目标，影响展示排序及聚焦任务筛选，不改变执行和生命周期；每条普通主线最多 3 个，独立目标共用 3 个名额，终态自动取消并释放名额。
8. 进行中目标可在独立区与在用普通主线之间、不同在用普通主线之间迁移；保持同一目标身份，下属任务随行，周期与历史记录保留，不重写历史归属。
9. 迁移原子校验源与目的状态及聚焦名额；保留聚焦，满额先提示调整，不挤占。成功后追加到目的位置同类展示组末尾，不改变其他目标相对顺序；失败或取消不改变状态。
10. 按独立成果或完整活动划分一次性任务；细步骤放检查清单，不单独计奖。
11. 创建每天或每周指定星期的周期任务，设置开始及可选结束日期，预览排期。
12. 查看今天、未来、过去和聚焦／全部任务，区分暂停、撤下、已结束和可执行任务。
13. 任务仅当天且未被相关目标或主线终态锁定时允许完成与取消完成；当天和未来可编辑安排，过去记录冻结，未来不可提前完成；目标达成和主线结束不允许取消。
14. 漏做的一次性任务可重新安排到今天或未来，保留原记录与新安排关联，同一行动不重复计奖。
15. 周期任务支持记录当天额外真实完成，增加实际次数和单次经验，不增加计划次数。
16. 周期暂停不排期，任务月按暂停天数顺延；恢复按原规则继续，保留长期积累。
17. 单独结束周期后停止推进、历史只读；所属主线未结束时保留已到期完整月资格，未满月不发周期奖励；主线结束的停止结算规则优先。
18. 重复规则可从今天或未来指定日期生效，预览安排、计划次数及奖励变化；过去记录、已结算月份、任务月起点与长期积累不变，取消不保存。
19. 任务完成保留稳定身份及当时的 mainlineId、goalId、taskId 和完成日期，独立任务的 goalId 为空；取消任务完成不追加冲正，奖励处理细节待后续讨论。
20. 按实际结果和完成标准手动确认目标达成；没有任务或仍有未完成任务也可以确认，任务全勾选不自动达成。
21. 目标达成进入已达成终态，不可撤销；其奖励计算保留既有独立规则，后续另行梳理，本轮不新增结算决策。
22. 确认达成或未达成而结束后，目标下全部一次性任务和周期任务停止，包括暂停周期；需要继续的任务应在确认前手动迁出。
23. 目标仅有进行中、已达成、未达成而结束三种生命周期结果；空目标、任务全完成或全迁出均不自动改变状态，终态只由目标手动确认或手动结束所属主线产生。
24. 到期任务月和奖励结算保留独立讨论范围；领域命令、重复提交、多设备和刷新均不得重复产生业务动作。终态只读不等同于已确认未入账奖励处置。
25. 任务月按原始起始日锚点计算，月末无对应日则取最后一天，暂停按天顺延；完整月到期即可结算。
26. 完成率最高 100%，完整任务月统一基数 10 XP，80% 达标，每笔最终奖励向下取整。
27. 每累计 3 个完整达标月，从下一任务月起长期系数复利增加 10%；本月未达标不使用系数，已有积累不清零。
28. 无计划次数的月份完成率不适用、不发周期奖励、不增加达标月；超额真实完成仍有单次经验，每月最多增加一个达标月。
29. 初始 Lv.1、0 XP，升级成本为 20+5×(当前等级−1) XP；等级只提供反馈，不改变功能或倍率；取消任务完成后的成长调整属于奖励机制后续讨论。
30. 行动 1／10／50／100 次、目标 1／3／10 个、单周期达标月 3／6／12 个月，共 10 类自动成就，不额外加分；奖励变动反馈另行梳理。
31. 事项历史保留当时来源、日期及内容；每次完成保存当时主线、目标、任务身份，后续改名、迁移不改写；奖励流水与取消完成的记录处理待后续讨论。
32. 成就展示条件、进度、差额、解锁日期与关联记录；同类长期徽章合并展示，按单周期判断；当天撤销后条件不满足则撤回成就。
33. 普通主线及目标的终态不可恢复；目标已达成和未达成而结束都退出聚焦，全部下属内容只读。确认前展示影响范围，取消确认无变化，确认成功后不可撤销；历史成果保留。
34. 角色、紧凑经验条、总体统计和成就横排展示服务端读回的即时进度，不继续显示任务或目标次日待结算流程。
35. 终态目标默认隐藏，需要时手动显示；详情保留名称、完成标准、归属、创建与终态时间、终态结果及下属任务历史，只读。已结束主线仍可进入查看其目标与历史。
36. 个人数据按真实账户隔离持久保存，刷新、换设备和服务重启不丢失，不改变首页既有任务来源。
37. 长时间未访问后补齐合法排期并按月顺序追赶到期完整月份，不以原型 28 天窗口截断。
38. 网络失败、重复请求和版本冲突提供清楚反馈；安全重试不丢失历史，不重复业务动作。
39. 原型独立推演不改变正式账户；正式接口不接受模拟日期、经验、账户归属或整包状态。
40. 新规则实现后重新进行需求、规范、安全及真实浏览器验收；既有检查不替代新规则验证，合并发布仍需具体授权。

## 结束、达成与迁移

### 结构与生命周期

普通主线 → 目标 → 一次性任务／周期任务；系统独立区 → 独立目标 → 任务，或系统独立区 → 独立任务。检查清单是任务内部步骤，不另成行动层级。普通主线最多 5 条在用，独立区不占名额、不能结束；独立目标数量不限。

| 当前状态 | 手动操作 | 结果 |
|---|---|---|
| 创建前 | 填写名称、完成标准并明确归属后提交 | 进行中；不自动聚焦，不自动创建任务 |
| 进行中 | 确认达成 | 已达成终态；退出聚焦，全部下属任务停止并只读 |
| 进行中 | 确认未达成而结束 | 未达成而结束的终态；退出聚焦，全部下属任务停止并只读 |
| 所属普通主线在用 | 确认结束主线 | 进行中目标进入未达成终态；原已达成结果保留，全部下属内容只读 |
| 任一终态 | 撤销、恢复、编辑、聚焦、迁移或新增任务 | 禁止，即使仍在当天 |

目标和主线只随使用者手动操作改变状态；空容器、任务／目标全部完成、全部结束或全部迁出均不自动推进上级状态。主线改名和管理目标不改变主线状态。目标达成以实际完成标准为准，不以任务数量或勾选率为门槛。

确认达成或结束前展示将被停止的未完成任务及周期。要继续的任务先手动迁出；确认后不能迁出绕过锁定，不提供达成后留在原目标继续的选项。第一版无删除目标、多阶段目标或终态恢复。

终态目标及全部下属任务禁止编辑、完成、取消完成、清单执行、暂停、恢复、结束或迁移。历史记录仍可查看，既有已完成、已达成与已入账事实不因结束被抹去。任务停止今天及未来未完成安排，不改写过去执行记录；奖励结算另议。

### 聚焦与查看

只有进行中目标可聚焦；每条普通主线最多 3 个，独立目标共用 3 个名额，不设全局 3 个上限。聚焦只改变目标展示顺序和所属任务筛选，不改变任务安排、完成记录或生命周期。

同一归属中先显示聚焦目标，再显示未聚焦目标，两组内部沿用手动顺序。进入终态自动取消聚焦并释放名额。终态目标默认隐藏，需要时手动显示；详情保留名称、完成标准、归属、创建时间、终态结果与时间，以及下属任务、原计划、完成记录、周期状态和历史归属。结束主线仍是查看其目标与历史的入口。开关粒度、持久化、终态具体排序及独立任务筛选尚未确认，不在本轮扩展。

### 迁移与历史归属

进行中目标支持独立区与在用普通主线之间及跨普通主线迁移。迁移保持目标身份，下属任务随行；聚焦状态保留，目的名额满时先调整，不自动挤占或取消聚焦。成功后追加到目的位置同类展示组末尾，保留其他目标的相对顺序；源／目的只读、失败或取消均不能产生半迁移。

任务可在可操作目标和独立身份之间迁移，也可在目标间迁移；普通主线不直接接收任务。任务身份、周期规则、起点、暂停状态与积累保留，迁移不恢复终态任务。

每次任务完成保存当时的 taskId、mainlineId、goalId 与完成日期；独立任务 mainlineId 指向系统独立区，goalId 为空。后续迁移不把过去行动归到新目标，不改写历史记录。已归属终态目标／主线的完成记录保持锁定，不能按任务当前新归属取消历史完成。

## 实时奖励与经验流水

本轮仅冻结目标操作边界，不展开奖励计算、删除或结算机制。任务完成及目标达成的即时反馈、周期公式与等级规则作为既有独立规则保留，不能据此恢复目标撤销或达成后继续周期。既有独立规则保留任务完成 +1 XP，以及目标达成时实际计奖行动次数 × 成就系数 1／2／3（跳过评价为 1、感想可选）的额外经验公式；本轮不重新决定其结算细节。

- 目标达成和主线结束不可取消；相关任务完成记录随上级终态锁定，即使当天也不能取消。
- 仅未被终态锁定的当天任务完成可取消，过去执行记录冻结，未来不能提前完成。
- 已确认取消任务完成采用删除对应奖励记录的方向，不追加负数冲正；删除边界、重试与成长重算细节留待奖励机制讨论。本轮不进一步决定完成历史或其他审计记录的删除范围。
- 目标／任务迁移不改写行动发生时的归属，不能把同一过去行动转入另一个目标重复计数。
- 终态只读限制用户操作，不推导后台待结算奖励的处置；主线结束既有未入账奖励停止规则保留，目标达成／结束后的未入账周期奖励如何处理留待后续明确。
- 经验流水解释奖励变化，命令 journal 用于请求重试去重；二者职责不混用。相关事务、去重和成长更新细节随奖励机制再核对。

## 周期奖励与等级

计划次数 P=0 时完成率不适用、奖励为零、不增达标月，并保留解释记录。P>0 时 R=min(实际完成次数 A/P,1)；本月之前累计达标月为 Q，累计系数 K=1.1^floor(Q/3)。本月 R≥0.8 才应用 K，否则适用系数为 1。奖励为 floor(10×R×适用系数)，中间不提前舍入；每个完整月最多新增一个达标月。

前三个达标月仍按原系数结算，之后的任务月才使用 1.1；累计六个达标月后，下一任务月可用 1.21。达标月不要求连续，不达标、暂停或结束不抹掉已有积累。额外完成不增加计划次数，检查清单不增加行动数或目标奖励次数。

升级成本为 20+5×(当前等级−1) XP；总经验 45 对应 Lv.3、当前进度 0/30。成就条件为行动 1／10／50／100、目标 1／3／10、单周期达标月 3／6／12，不额外发经验。取消任务完成后的等级、统计与成就重算细节留待奖励机制讨论；本段不授权撤销目标达成。

## 服务端与数据边界

模块尚未上线，没有需要兼容的线上用户历史。本期直接按新规范实现，不要求旧支线结构或旧次日奖励数据迁移。本地及验收数据不作为正式历史；是否清理需另行明确，本次不操作数据。

- 服务端强制校验系统独立区与普通主线区别、目标／独立任务归属、名称及完成标准必填、分组聚焦名额、迁移、终态只读、日期冻结和幂等；不能只靠 UI 禁用。
- 复用现有 Supabase 独立 adventure_states(owner_id,state,version,journal)。Worker 在线验证身份，只访问当前 owner；浏览器无直接表权限，禁止客户端整包 state 写入。首页共享 tasks／schedules 不迁入。
- 所有普通变更带 expectedVersion，失配返回 409，刷新后重新确认，不自动覆盖旧视图意图。owner＋requestId 日志与状态通过版本 CAS 同次提交，同 key 异 payload 拒绝，未知结果保留原 key 重试；响应返回最新状态和稳定命令结果，客户端防倒序覆盖。
- GET 只读取／初始化，页面随后 POST refresh 追赶有结算资格的已到期完整任务月，排除已结束主线下全部未入账奖励；任务与目标奖励在相应业务命令内实时提交。只有 refresh 可有限重读重算，普通变更不可自动重放。
- 规划时区固定 Asia/Shanghai，采用服务端权威时间，与首页天气地区独立。新账户从 Lv.1、0 XP 开始，不导入原型虚构历史。
- 完整持久行 UTF-8 预算 8,000,000 bytes，超限拒绝且原数据可读，不裁剪历史、流水或幂等记录。独立目标无业务数量上限不等于存储容量无限。
- 周期规则按生效日期版本化，过去冻结；计划数依据有效规则及暂停区间计算，不依赖展示窗口。单实例改期保留原槽位和分母所属月，实际按执行日期计入，额外完成无计划槽位。

## 验收标准

- 5 条在用普通主线及结束释放名额；系统独立区固定、不占名额且不能结束；普通主线不能直接挂任务，目标及独立任务归属明确。
- 名称及完成标准必填，无默认归属、草稿、多阶段或目标删除；进行中可修改，取消不保存，改标准不自动达成。
- 每主线 3 聚焦、独立目标共用 3 个；仅进行中可聚焦，终态自动取消；聚焦在前且组内沿用手动顺序，筛选保留，未聚焦仍可推进。
- 目标空、任务全完成／结束／迁出均不自动变状态；无任务或有未完成任务均可按标准手动达成；主线仅手动结束，下属变化不自动结束主线。
- 达成、未达成而结束、手动结束主线的终态传播；已达成及完成历史保留，所有下属任务只读，即使当天也不可撤销、恢复或迁出。
- 三种目标迁移、任务目标／独立身份迁移、聚焦满额及源／目的只读校验；目标连同任务迁移，目的同类组末尾落位，失败或取消无部分改变。
- 每次完成保存当时主线、目标、任务身份及日期，独立任务无目标；改名迁移不重写历史、不把过去行动转计新目标，历史终态锁定不能被当前归属绕过。
- 终态目标默认隐藏、可手动显示、详情只读；已结束主线仍能进入查看目标及历史。
- 奖励结算和取消完成后的记录处理待独立梳理，不能沿用负数冲正、先撤目标再撤任务或达成后继续周期作为本轮验收要求。
- 原有账户隔离、数据库权限／CAS、版本冲突、超时幂等、跨刷新持久、小屏及键盘约束继续有效；新目标规则须重新验证，旧报告不作为通过证据。
