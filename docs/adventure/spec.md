# 人生冒险模块规格

状态：本分支集成 #164／#168 的目标分类模型；验证及未完成项见 [集成验收](qa-goal-integration.md)。本地实现不代表人工验收、生产迁移、合并或发布授权。

## 目标与范围

人生冒险围绕目标、完成标准与日常行动组织规划和成长记录。页面包含今日聚焦、目标和成长记录；周期性任务不在本期范围内。目标控制台采用 D34 确认的原型 C；今日聚焦和成长记录保持既有查询、筛选及任务奖励行为。

## 目标

- 目标是唯一主结构；名称和至少一项非空完成标准必填。可选分类标签去除首尾空白后为 1–200 字符，空白表示无标签；同名标签互不关联，不参与分组、排序、筛选、配额、权限或生命周期。
- 单一列表先显示进行中目标并按账户级手动顺序排列；显示终态时追加按终态时间倒序、ID 决胜的终态目标。分页和按账户浏览器保存的终态开关保留。focused 的原值保留但不用于目标列表排序或筛选，此页不提供聚焦操作。
- 创建和编辑不选择主线；编辑不改变目标身份、任务或历史。目标仅有进行中、已达成、已结束；任务全部完成不自动达成。达成或结束前须删除或转移未完成任务，预览和事务均检查；终态不可恢复或编辑，已有成果只读保留。
- 关系卡片显示目标详情，翻面后的相关任务仅含当前属于目标、未删除的待完成与已完成任务，显示名称、计划和完成时间；历史奖励来源独立保留。点击卡外只关闭卡片，背景锁定。
- 旧普通主线名称迁为所属目标的标签，独立目标标签为空；初始顺序与清理细节见 [目标分类迁移](goal-category-migration.md)。旧主线及纯主线操作历史删除，保留其他历史事实与非主线快照；旧完成和达成不补写标签，新完成与达成冻结发生时标签。

## 一次性任务

### 创建与状态

任务代表一个独立成果或一次完整行动，同一行动只完成一次。任务类型创建后不可转换。创建填写名称、执行日期，说明可选；归属选择框只列可操作目标，未选择或清空则由后端保存为独立任务，不额外列“独立任务”选项。本期只有一次性任务，不展示周期设置、暂停、额外完成、检查清单或计划结束日期入口。

| 状态 | 含义 | 允许操作 |
|---|---|---|
| 待完成 | 仍准备执行的一项行动 | 统一编辑名称／说明／日期／归属、符合日期条件时完成、从编辑卡片删除 |
| 已完成 | 同一行动已有一条有效完成记录 | 查看；完成当天且未锁定时取消完成 |
| 已结束（旧数据） | 旧规则下停止执行的任务 | 不再新增；仅对已授权范围准备保留历史的清理 |

逾期是日期提示，不是终态。逾期任务可以直接在今天完成，或在统一编辑中重新安排；不再执行的未完成任务可从编辑卡片删除，不提供单独结束任务功能。

新建和编辑共用任务表单，一次提交名称、说明、执行日期和归属。新建默认名称及说明为空、日期为北京时间今天、归属为独立任务，与周历选中日期无关。编辑预填四项；逾期任务不改原日期时可以修改其他字段，修改日期时只能选择今天或未来。取消不写入，已完成任务不可编辑或改变归属。日期控件仅选择日期，点击输入框、横条或图标可打开日历，分段修改数字与日历同步，选择可确认或取消。

### 完成与取消完成

- 规划时区固定 Asia/Shanghai，由服务端确定当天。计划执行日为今天或之前的待完成任务都可在今天完成；保留计划日期，实际完成日由服务端记录为今天。未来不可提前完成，也不可补写过去完成；提前做完须先编辑计划日期到今天。
- 任务、当前上级及记录形成时的历史归属不得处于终态锁定。同一行动最多一条有效完成记录，双击、刷新、重试、多设备并发均不得重复计数。
- 每次完成保存稳定 taskId、goalId、完成日期及当时名称、说明、分类标签和来源快照；独立任务的 goalId 和分类标签为空。旧完成不补写分类标签。
- 仅完成当天且任务和相关上级未终态锁定时可取消；取消针对具体完成记录，一次性任务恢复待完成并保留原计划日期；原计划日已过则恢复逾期。过去完成记录冻结；目标达成或结束后不能取消；旧主线结束形成的历史锁定仍有效。
- 完成和撤销完成均点击圆钮直接提交；撤销不读取确认预览或打开弹窗。版本冲突只重读并等待再次点击，未知结果仅以原封套安全重试；奖励回退由服务端完成。
- 取消完成后，用户界面直接移除该完成记录，数据库逻辑删除保留，不展示反复完成／取消的审计过程。所有业务计数、进度及有效完成查询排除逻辑删除记录。
- 再次完成仍是同一任务和同一行动，只计算一条有效完成记录；撤销后仍可删除任务，删除不能再次扣除已失效奖励。完成／取消与版本、幂等记录同次原子提交，不能因超时重试复活已取消的完成或产生第二次业务动作。
- 完成与 1 点任务奖励同时实时提交；取消完成时，对应完成与奖励同时逻辑删除，不追加负数冲正。按有效事实实时计算总经验、等级、行动数及成就，不单独保存等级／成就状态或解锁日期，详见 [成长与奖励规则](growth-rewards.md)。

### 统一编辑与删除

日期和归属只通过统一编辑修改，不再提供任务独立改期、迁移或结束入口及新请求能力；历史成功请求仍按原回执重放。编辑保留任务／行动身份，日期和归属变更保留发生时快照及来源，不重写完成事实。

当前上级可操作的所有未完成任务均可从编辑卡片逻辑删除，包括今天、逾期、未来及完成后撤销的任务；详情不提供删除按钮。删除从当前列表和目标进度排除任务，保留历史事件、奖励和成功回执。已完成任务删除不在范围内。已有已结束任务仅按已授权范围处理，先核实真实数据与历史引用，不清空其他任务、完成、奖励或账户数据。

删除先读取服务端预览，正常确认框标题为“删除任务”，单段确认文案，仅“取消／确认删除”两项操作；版本失效时才显示重新预览。提交前取消、关闭或 Escape 返回原编辑卡片并保留四字段草稿；删除针对原任务，不提交尚未保存的表单值。提交后或结果未知时，关闭操作会关闭整个弹窗，恢复仍遵守原封套重试规则。

## 今日聚焦与周历

使用 Asia/Shanghai 日期，周历按周一至周日排列，进入页面默认今天；可切换上一周、下一周，保留选中星期几，并可回到今天。日期格显示星期、日期及“今天”提示，不显示任务数量或任务标记；跨午夜不要求自动切换。

过去日期仅显示实际在该日完成的任务；未来显示计划在该日执行的待完成任务。今天分为逾期待完成、今日待完成、今日已完成；逾期按原计划日升序，今天完成的逾期任务进入今日已完成。任务创建日期不参与日期归类，仅用于稳定排序。任务行保留独立完成／撤销圆钮、未完成任务的行内编辑和独立详情箭头；过去／未来圆钮禁用。右侧日期显示月日，并以完整日期提示补充年份；详情箭头展开向上、收起向下，展开仅显示说明，不重复展示安排记录。

所选日期任务通过独立 POST 列表接口每批 10 条完整获取，须验证账户、日期和版本一致，处理过期响应、并发变化及失败恢复。接口不搜索，前端在完整结果中搜索名称与说明，再对三个分组统一每页 20 条；分组数量取搜索后的全量结果，切换日期保留搜索词。此接口本期不接入目标详情。布局在日期切换、翻页和详情展开时保持稳定；执行日期数字与日历入口共用完整外框；仅人生冒险页隐藏根滚动条，滚动及今日进度继续可用。

## 迁移与历史归属

未完成任务可在统一编辑中改变目标或独立身份，保留任务身份、执行安排、状态和历史；历史完成按发生时目标归属，不因改名、改标签或迁移改写，也不转计新目标。记录形成时的终态锁定不能通过改变当前归属绕过。目标跨主线迁移命令已退役。

## 成长与进度

本期成长和奖励的完整规则及操作案例见 [成长与奖励规则](growth-rewards.md)，与本规格共同作为验收依据。

- 每次有效任务完成实时奖励 1 点经验；目标达成按历史有效计奖行动次数 N × 成就系数 1／2／3 额外奖励，N=0 时固定奖励 1 点、不乘系数。默认／跳过评价取 1，感想可选，达成前预览奖励及影响，确认后冻结。
- N 按完成时所属目标计数，取消记录不计入；改名、改期及迁移不重复计数，不把历史行动转给新目标。目标达成不增加行动数。
- 取消完成和对应奖励一起逻辑删除，界面及有效统计排除，数据库保留；总经验为有效奖励之和，等级和成就实时计算，不单独保存等级、成就状态或解锁日期，不展示解锁日期。
- 初始 1 级、0 经验，升级成本 20+5×(当前等级−1)；全账户统一等级，不影响功能或奖励倍率。取消可以回退等级；已入账成果不因结束、改名或迁移扣减。
- 行动 1／10／50／100 次和目标 1／3／10 个，共七个成就里程碑，不额外加经验；全部展示，满足条件点亮，否则显示进度及差额，条件不再满足则实时恢复未点亮。
- 成长页面只读展示等级经验条、总经验、七个成就、有效奖励流水及行动／目标统计。任务完成与合法撤销直接执行并反馈服务端成长变化；目标达成统一确认后同时入账和进入终态。
- 没有次日、待入账或刷新补发流程，结束不额外发奖、已入账事实保留；本期没有周期奖励、任务月或达标比例要求。
- 任务汇总进度条与等级经验条分开。今日进度按所选任务视图的完整今日结果计算为今日已完成数／（逾期待完成＋今日待完成＋今日已完成），不受搜索或分页影响；过去和未来不显示进度条。目标进度由后端按当前归属的全部日期任务计算为已完成数／（待完成数＋已完成数），排除已结束、已删除任务及无效完成；分母为零显示“暂无可统计任务”，不显示 100%。迁出任务不计当前目标进度，历史行动及奖励仍按发生时归属；目标汇总不因列表分页截断，进度不自动决定目标达成。
- 聚焦视图显示聚焦目标下任务及独立任务；全部视图显示全部目标下任务及独立任务，两者的日期和归属范围由后端确定，今日聚焦的搜索与分页在前端完成。

## 服务端与数据边界

- 账户、目标、任务、事件四张表按账户隔离；inbox 按首次独立操作创建且不作为真实目标，读取不预建。Worker 验证身份及准入，浏览器无直接表或 RPC 权限；业务写入通过 service_role 专用事务。
- 事务锁定账户，先检查历史成功回执，再核对 expectedVersion；同账户、同 requestId 和规范化命令摘要重放清理后结果，异摘要冲突，旧停用命令不得新执行。历史回执不保存 expectedVersion，重放不能证明该字段与原请求相同。纯主线操作及回执删除，客户端不得跨命令复用旧 requestId；无法安全重放的旧结果明确拒绝。
- 保留账户 revision、total_xp、账户中已有的时区字段、目标与任务身份、奖励和非主线历史；total_xp 等于有效冻结奖励之和。日期边界仍使用规划时区。旧主线结束原因中性化，历史锁定保留，不以当前数据重算历史。
- 严格拒绝旧主线参数及退役命令；公开接口、共享类型和数据库不包含主线结构。客户端与 Worker／数据库须协调切换，维护窗口方案及其限制见 [集成验收](qa-goal-integration.md)。

只读接续接口 `POST /api/adventure/receipts/lookup` 使用原账户有效会话，接收原封套的 `requestId`、`expectedVersion`、`command` 和每次查询新生成的 `nonce`（32 字节安全随机数的小写 64 位十六进制，不持久化）。服务端按认证账户、requestId 和规范化命令摘要查询，成功返回 `{requestId, nonce, receipt: {version, result}}`，附模型标识和 `Cache-Control: no-store`。`result.source` 可选，保留已识别的非主线来源字段；未知或无法安全重放的结构返回 `REPLAY_UNAVAILABLE`。客户端须核对原封套 requestId、本次 nonce、响应头及回执结构后才可清除封套；失败或安全随机数不可用时保持待确认。此关联可发现响应错位，但不能抵御能够篡改请求和响应的恶意代理；它不验证旧 expectedVersion，也不执行命令。详细错误和切换边界见[集成验收](qa-goal-integration.md)。
- 旧版 [数据库设计](backend-database.md)、[业务逻辑](backend-business-logic.md) 和 [接口契约](planning-api.md) 保留为 PR #146 历史；涉及主线的内容不适用于本分支，当前变更以 #168、迁移文档和代码为准。

## 验收与交付

验收须覆盖隔离非空旧库与新库、逐账户逐 ID 对账、失败回滚、重复执行、权限、并发与回执，以及浏览器经 Worker 到隔离数据库的目标、关系、任务与成长流程；不得将模拟或跳过当作通过。人工界面验收、生产迁移及发布均须在自动验证和评审之后另行安排。历史验收与旧五表规格不能作为本分支通过证据。
