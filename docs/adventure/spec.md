# 人生冒险模块规格

状态：今日聚焦变更依据 #140／#141 与 #142–#145 在集成分支实施；本文件为当前目标行为。历史交付证据见 [交付验收](qa-integration.md)，本次验证单独记录，人工及发布验收尚未完成。

## 目标与范围

帮助使用者组织长期方向、阶段结果和当天行动。本期实现普通主线、独立目标、一次性任务及其历史，以及配套成长和奖励机制；周期性任务及相关设计归入 [待办](backlog.md)，不作为本期开发、验收或交付前置条件。不加入检查清单和计划结束日期。

前端采用已选定的 A 行动工作台，页面包含今日聚焦、主线与目标、成长记录，保留像素个人形象、紧凑经验条、右侧统计和成就横排；页面、职责和接口能力需求见 [前端设计](decisions-frontend.md)。任务进度使用进度条，不设置达标比例或达标／未达标判断；统计口径见下文“成长与进度”，不自动判定目标达成。

## 主线与目标

- 普通主线是长期方向，最多 5 条在用，只通过目标承载任务，不能直接挂任务。只提供创建、改名和手动结束；空主线、目标全部达成／结束／迁出均不自动结束。结束不可恢复，释放在用名额。
- 系统独立区固定存在，不占普通主线名额且不能结束，承载数量不限的独立目标和不依附目标的独立任务。界面使用独立目标／独立任务，不显示另一条普通主线容器。
- 目标名称必填，完成标准至少一项且可多项；归属未选择时默认独立目标，选择框只列在用普通主线，也可清空归属转回独立目标。进行中可修改名称、标准和归属；取消不保存，修改不触发达成。第一版不删除目标，不提供草稿或多阶段目标。
- 目标仅有进行中、已达成、未达成而结束三种状态。空目标、任务全部完成／结束／迁出不自动改变目标状态；可依据实际完成标准手动确认达成；如仍有未完成任务，须先删除或转移后再确认。
- 聚焦仅适用于进行中目标，只影响展示排序和所属任务筛选；每普通主线最多 3 个，独立目标共用 3 个，终态自动取消并释放名额。同一归属中先聚焦后未聚焦，组内沿用手动顺序；未聚焦仍可执行任务。

| 当前状态 | 操作 | 结果 |
|---|---|---|
| 创建前 | 填写名称、完成标准和归属并确认 | 进行中，不自动聚焦或创建任务 |
| 进行中 | 确认达成 | 已达成终态，全部下属任务停止并只读 |
| 进行中 | 确认未达成而结束 | 未达成终态，全部下属任务停止并只读 |
| 所属普通主线在用 | 确认结束主线 | 进行中目标进入未达成终态；已有达成结果保留，下属全部只读 |
| 任一终态 | 撤销、恢复、编辑、聚焦、迁移或新增任务 | 禁止，即使仍在当天 |

达成或结束目标、结束主线前，必须先删除或通过统一编辑转移当前归属下的未完成任务；服务端在预览和最终事务均检查，不自动删除、迁移或结束任务。取消确认无变化。确认后不能迁出绕过锁定，不提供达成后继续下属任务的选项。“主线与目标”页统一使用“显示已达成／已结束”开关，默认隐藏终态目标与已结束主线；开关按账户保存在当前浏览器，刷新保留、不跨设备同步。后端将进行中内容排在前面，保留聚焦及组内手动顺序；终态目标在所属分组末尾按终态时间倒序，已结束主线在主线列表末尾。隐藏不影响历史、成长流水和来源详情访问。目标详情保留名称、完成标准、归属、创建及终态时间、结果和任务历史。已结束主线仍可进入查看目标与历史。

## 一次性任务

### 创建与状态

任务代表一个独立成果或一次完整行动，同一行动只完成一次。任务类型创建后不可转换。创建填写名称、执行日期，说明可选；归属选择框只列可操作目标，未选择或清空则由后端保存为独立任务，不额外列“独立任务”选项。本期只有一次性任务，不展示周期设置、暂停、额外完成、检查清单或计划结束日期入口。

| 状态 | 含义 | 允许操作 |
|---|---|---|
| 待完成 | 仍准备执行的一项行动 | 统一编辑名称／说明／日期／归属、符合日期条件时完成、从编辑卡片删除 |
| 已完成 | 同一行动已有一条有效完成记录 | 查看；完成当天且未锁定时取消完成 |
| 已结束（旧数据） | 旧规则下停止执行的任务 | 不再新增；仅对已授权范围准备保留历史的清理 |

逾期是日期提示，不是终态。逾期任务可以直接在今天完成，或在统一编辑中重新安排；不再执行的未完成任务可从编辑卡片删除，不提供单独结束任务功能。

新建和编辑共用任务表单，一次提交名称、说明、执行日期和归属。新建默认名称及说明为空、日期为北京时间今天、归属为独立任务，与周历选中日期无关。编辑预填四项；逾期任务不改原日期时可以修改其他字段，修改日期时只能选择今天或未来。取消不写入，已完成任务不可编辑或改变归属。日期控件仅选择日期，点击输入框、横条或图标可打开日历，分段修改数字与日历同步，选择可确认或取消。

### 完成与取消完成

- 规划时区固定 Asia/Shanghai，由服务端确定当天。计划执行日为今天或之前的待完成任务都可在今天完成；保留计划日期，实际完成日由服务端记录为今天。未来不可提前完成，也不可补写过去完成；提前做完须先编辑计划日期到今天。
- 任务、当前上级及记录形成时的历史归属不得处于终态锁定。同一行动最多一条有效完成记录，双击、刷新、重试、多设备并发均不得重复计数。
- 每次完成保存稳定 taskId、mainlineId、goalId、完成日期及当时名称、说明和来源快照；独立任务的 mainlineId 指向系统独立区，goalId 为空。
- 仅完成当天且任务和相关上级未终态锁定时可取消；取消针对具体完成记录，一次性任务恢复待完成并保留原计划日期；原计划日已过则恢复逾期。过去完成记录冻结；目标达成、目标结束、主线结束不能取消。
- 取消完成后，用户界面直接移除该完成记录，数据库逻辑删除保留，不展示反复完成／取消的审计过程。所有业务计数、进度及有效完成查询排除逻辑删除记录。
- 再次完成仍是同一任务和同一行动，只计算一条有效完成记录；撤销后仍可删除任务，删除不能再次扣除已失效奖励。完成／取消与版本、幂等记录同次原子提交，不能因超时重试复活已取消的完成或产生第二次业务动作。
- 完成与 1 点任务奖励同时实时提交；取消完成时，对应完成与奖励同时逻辑删除，不追加负数冲正。按有效事实实时计算总经验、等级、行动数及成就，不单独保存等级／成就状态或解锁日期，详见 [成长与奖励规则](growth-rewards.md)。

### 统一编辑与删除

日期和归属只通过统一编辑修改，不再提供任务独立改期、迁移或结束入口及新请求能力；历史成功请求仍按原回执重放。编辑保留任务／行动身份，日期和归属变更保留发生时快照及来源，不重写完成事实。

所有未完成任务均可从编辑卡片逻辑删除，包括今天、逾期、未来及完成后撤销的任务；详情不提供删除按钮。删除从当前列表和目标进度排除任务，保留历史事件、奖励和成功回执。已完成任务删除不在范围内。已有已结束任务仅按已授权范围处理，先核实真实数据与历史引用，不清空其他任务、完成、奖励或账户数据。

## 今日聚焦与周历

使用 Asia/Shanghai 日期，周历按周一至周日排列，进入页面默认今天；可切换上一周、下一周，保留选中星期几，并可回到今天。日期格不额外显示数量或标记，跨午夜不要求自动切换。

过去日期仅显示实际在该日完成的任务；未来显示计划在该日执行的待完成任务。今天分为逾期待完成、今日待完成、今日已完成；逾期按原计划日升序，今天完成的逾期任务进入今日已完成。任务创建日期不参与筛选。右侧显示计划日期及适用的实际完成日期；详情箭头可点击，展开向上、收起向下，不重复展示安排记录。

所选日期任务通过独立 POST 列表接口完整获取，可分批但须验证账户、日期和版本一致，处理过期响应、并发变化及失败恢复。接口不搜索，前端在完整结果中搜索名称与说明，再对三个分组统一分页；切换日期保留搜索词。此接口本期不接入目标详情。

## 迁移与历史归属

进行中目标可在独立区与在用普通主线间、不同在用普通主线间迁移，保留身份，下属任务随行。保留聚焦，先校验目的名额，满额先调整，不挤占其他目标；成功后追加到目的同类展示组末尾，其他目标相对顺序不变。源／目的只读、失败或取消均不产生半迁移。

未完成的一次性任务通过统一编辑支持目标间迁移，以及目标与独立任务身份互转；普通主线不直接接收任务。迁移保留任务身份、执行安排、状态和历史，不恢复已结束任务。历史完成固定当时主线、目标、任务身份与日期，不因改名或迁移改写，不把过去行动转计新目标。记录原归属进入终态后，不能按当前新归属取消历史完成。

## 成长与进度

本期成长和奖励的完整规则及操作案例见 [成长与奖励规则](growth-rewards.md)，与本规格共同作为验收依据。

- 每次有效任务完成实时奖励 1 点经验；目标达成按历史有效计奖行动次数 N × 成就系数 1／2／3 额外奖励，N=0 时固定奖励 1 点、不乘系数。默认／跳过评价取 1，感想可选，达成前预览奖励及影响，确认后冻结。
- N 按完成时所属目标计数，取消记录不计入；改名、改期及迁移不重复计数，不把历史行动转给新目标。目标达成不增加行动数。
- 取消完成和对应奖励一起逻辑删除，界面及有效统计排除，数据库保留；总经验为有效奖励之和，等级和成就实时计算，不单独保存等级、成就状态或解锁日期，不展示解锁日期。
- 初始 1 级、0 经验，升级成本 20+5×(当前等级−1)；全账户统一等级，不影响功能或奖励倍率。取消可以回退等级；已入账成果不因结束、改名或迁移扣减。
- 行动 1／10／50／100 次和目标 1／3／10 个，共七个成就里程碑，不额外加经验；全部展示，满足条件点亮，否则显示进度及差额，条件不再满足则实时恢复未点亮。
- 成长页面只读展示等级经验条、总经验、七个成就、有效奖励流水及行动／目标统计。任务完成直接反馈，取消有成长影响时先确认；目标达成统一确认后同时入账和进入终态。
- 没有次日、待入账或刷新补发流程，结束不额外发奖、已入账事实保留；本期没有周期奖励、任务月或达标比例要求。
- 任务汇总进度条与等级经验条分开。今日进度按所选任务视图的完整今日结果计算为今日已完成数／（逾期待完成＋今日待完成＋今日已完成），不受搜索或分页影响；过去和未来不显示进度条。目标进度由后端按当前归属的全部日期任务计算为已完成数／（待完成数＋已完成数），排除已结束、已删除任务及无效完成；分母为零显示“暂无可统计任务”，不显示 100%。迁出任务不计当前目标进度，历史行动及奖励仍按发生时归属；目标汇总不因列表分页截断，进度不自动决定目标达成。
- 聚焦视图显示聚焦目标下任务及独立任务；全部视图显示全部目标下任务及独立任务，两者的日期和归属范围由后端确定，今日聚焦的搜索与分页在前端完成。

## 服务端与数据边界

物理表与内部事实结构见 [后端数据库设计](backend-database.md)，命令、能力、预览及原子性见 [后端业务逻辑](backend-business-logic.md)。五表、命令事务及投影已在交付分支实现并由临时隔离数据库验证；接口采用页面查询、操作预览和业务命令，本票契约见 [主线与目标接口](planning-api.md)。

- 个人内容按真实账户隔离持久保存，首页共享 tasks／schedules 不迁入。不假设数据库为空；保留既有数据及历史回执，真实数据升级在明确授权范围内执行。
- 后端采用 [五张关系表](backend-database.md)：账户汇总、主线、目标、任务与事件。事件同时保存历史、奖励和成功请求回执；奖励冻结于 task_completed／goal_achieved，账户 total_xp 由事务与有效完成／达成事件的冻结金额同步维护，等级和成就实时计算。Worker 在线验证身份，浏览器无直接表或事务函数权限，禁止客户端指定 owner、经验、规划日期或整包状态。
- 普通变更带 expectedVersion，与账户 revision 核对；事务先锁账户行，当前实体、事件、total_xp、版本及成功回执同事务提交。失配返回 409、重读确认，不自动重放；同 key 异命令拒绝，未知结果原 key 重试，客户端防倒序覆盖。
- 接口分为页面查询、操作预览、业务命令：查询按页返回后端计算的事实、统计、进度、排序、能力、版本与规划日期；预览返回确认影响且不写业务数据、不推进版本；命令重新校验并原子提交，返回稳定操作结果和版本，前端随后重新查询当前页面。命令已成功但查询失败时明确提示并只重试查询；结果未知沿用原请求安全重试，版本冲突重读确认。
- 读取只返回当前事实及实时成长，首次账户初始化例外；独立主线与 inbox 按首次独立操作创建并复用。五表读取保持同一账户版本。完成、取消和达成通过后端专用数据库事务入口处理，不能逐表独立 REST 写入。改期、删除、迁移和刷新不产生奖励。
- 服务端校验归属、必填字段、聚焦配额、日期冻结、单行动有效完成唯一性、任务删除条件、迁移与终态只读，并向前端返回操作能力、不可操作原因及必要预览。前端只处理展示、交互级边界、输入格式与文案拼接，不复制业务算法或从名称解析身份；最终提交始终重新校验。逻辑删除作用于对应关系表记录，不物理删除业务历史、账户元数据或命令回执，不授予后端物理 DELETE。
- 分记录限制文本长度、分页与事务返回量，不使用整账户 JSON 单行 8 MB 预算。超限拒绝整笔操作，保留原数据，不能部分传播终态或裁剪历史、逻辑删除、流水及回执。

## 验收标准

- 普通主线最多 5 条在用，手动结束释放名额；独立区固定、不占名额、不能结束；主线不能直接挂任务。
- 目标名称及非空标准必填、归属可选或清空且后端默认独立、编辑、排序、聚焦、手动达成／结束、终态传播与只读、隐藏／显示及历史查看符合本版。
- 本期只创建一次性任务；名称、可选说明、执行日期、归属正确，无周期、暂停、额外完成、清单和计划结束日期入口。
- 待完成／已完成、逾期完成、实际完成日期、过去只读及未来不可提前完成具有新验证证据。
- 完成、取消、再次完成只保留一条有效完成；逻辑删除不出现在界面或业务统计，数据库记录和命令幂等证据保留，终态与跨日不能取消。
- 统一编辑保留原安排和来源，同一行动单一有效安排；不提供任务结束；已完成结果不被上级终态抹去。
- 删除覆盖所有未完成任务及撤销后任务，不重复扣奖，不改变其他任务或目标；目标终态前存在未完成任务时阻断。
- 目标与任务迁移保留身份、历史、聚焦配额及落位，失败／取消无部分改变；不能经迁移绕过历史终态锁定。
- 2 项完成、1 项待完成、1 项结束显示 2／3；零分母显示空进度，迁出不计当前进度且不改历史奖励；独立任务在两种筛选中可见。统一终态开关、浏览器按账户记忆、终态排序及隐藏后详情访问均有新证据。
- 主要业务验收边界为正式 HTTP 接口到真实数据库事务，提交后重新读取并验证事实、奖励、版本、回执及持久化；隔离数据库覆盖事务回滚、外键、权限和并发，不以模拟成功代替。浏览器覆盖关键流程、刷新和手机布局；计算测试仅补必要临界值。
- 成长与奖励的实时原子入账、逻辑删除、1 点保底、历史计奖归属、等级回退、七个动态成就及不保存解锁状态，按 [操作案例](growth-rewards.md) 重新验证。
- 账户隔离、五表事务与版本校验、日期、并发重试、跨刷新持久化及首页新闻回归重新验证；周期票不阻塞本期任务，旧测试／评审不作为本版通过证据。
