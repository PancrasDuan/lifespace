# 人生冒险：主线、目标、一次性任务与实时成长规格

状态：2026-10-20 已确认，待按本版实现和重新验收。本规格替换本 Issue 的旧范围；本次发布不代表功能、数据库或部署已经完成。

## 问题陈述

使用者需要把长期方向、阶段结果和日常行动组织在一起，清楚看到今天能做什么、哪些目标值得关注，以及真实行动和成果带来的成长。目标不能仅因任务勾选完毕就自动达成，改期和迁移不能改写过去，失败、重复提交或多设备操作也不能造成丢失或重复奖励。

## 解决方案

提供人生冒险页面，采用已选定的 A 行动工作台，包含冒险概览、主线与目标、成长记录。以普通主线、独立目标和一次性任务组织个人规划，按真实账户隔离保存；完成任务和确认目标达成时实时入账，等级与七个成就从有效事实计算。核心规则由后端统一计算和校验，前端负责展示、输入、确认、提交及重新查询。

## 实现决策

- 范围为普通主线、独立目标、一次性任务、历史、成长与奖励；采用 A 行动工作台，保留像素角色、紧凑经验条、右侧统计及成就横排。
- 普通主线最多 5 条在用，手动结束不可恢复；目标有进行中、已达成、未达成而结束三态。终态向当前下属传播只读，既有完成与奖励保留，不提供达成后继续下属任务。
- 系统独立区固定存在、不占配额且不能结束。物理层独立任务引用隐藏的唯一 inbox；对外表达为独立任务，不当作真实目标计数、达成、聚焦或奖励。
- 一次性任务保持稳定身份，待完成、已完成、已结束三态；改期不创建另一项行动，已完成不直接改期，取消必须定位具体完成记录。
- 服务端固定规划时区 Asia/Shanghai，仅当天安排可完成；当前及历史归属终态锁定均在事务中校验。过去完成冻结，误建删除必须校验所有历史资格。
- 目标迁移保留聚焦、先验名额、任务随行，落在目的同类组末尾；任务迁移只改变当前归属。历史内容、完成归属和目标奖励依据不被重写。
- 任务进度由后端按当前归属及明确查询范围计算：已完成／（待完成＋已完成），排除已结束、已删除及无效完成；分母为零返回空进度。目标汇总不因任务列表分页截断。历史行动和奖励另按发生时归属统计。
- 聚焦视图包含聚焦目标下任务及独立任务，全部视图包含全部目标下任务及独立任务；两者均受日期和搜索条件约束，后端执行筛选。
- “主线与目标”页统一“显示已达成／已结束”开关默认关闭，按账户保存在当前浏览器，不跨设备同步。后端排序：进行中优先、聚焦及手动顺序保留；终态目标在各自分组末尾按终态时间倒序，已结束主线在主线列表末尾。隐藏不影响历史和流水详情。
- 任务有效完成奖励 1 点；目标按完成当时归属、达成时仍有效且按稳定任务身份去重的行动数 N 计奖，N>0 时为 N×C，N=0 时固定 1；C 为 1／2／3，默认 1。达成事实、评价、依据和奖励冻结且不可撤销。
- 取消完成同时逻辑失效原完成和任务奖励，不追加负数奖励。总经验等于有效奖励之和；初始 1 级、0 经验，升级成本 20+5×(当前等级−1)。等级及七个动态成就实时计算，不保存或展示解锁日期。
- 五张专用关系表分别保存账户汇总、主线、目标、任务、事件；事件保存历史、奖励、快照与成功回执。任务只保留当前日期，改期历史保存在事件中；编辑名称和说明记录 task_updated 事件及前后快照。
- 后端专用数据库事务锁定账户行，先查成功回执、再核对 expectedVersion；实体、事件、total_xp、revision 和回执同次提交。所有成功命令有对应事件，失败全部回滚；同 key 异命令拒绝，幂等查询包含已失效事件。
- 五表启用 RLS 和同 owner 关联，浏览器无直接表或事务函数权限；后端在线验证身份与准入，不信任客户端指定 owner、经验、规划日期或整包状态。不改首页共享任务来源。
- 后端负责业务校验、日期、计奖、统计、进度、筛选、排序、能力和预览；前端只负责展示、输入格式、确认、请求、加载及错误状态，不乐观修改业务事实。
- 接口分为页面查询、操作预览、业务命令。查询按页返回后端投影、版本、规划日期及能力；预览不写业务数据、不增加版本；命令重新校验并原子提交，返回稳定操作回执及版本，前端随后重新查询。具体端点、字段名、错误码、分页和输入／事务预算由实施时的契约定义固定并测试，不再改变已确认语义。
- 需要确认时先预览；命令成功但查询失败时明确区分操作成功与页面更新失败，只重试查询。结果未知时在内存保留原 requestId、expectedVersion 和输入安全重试；409 重新读取并确认，不自动重放。客户端拒绝旧账户及倒序响应覆盖。
- 查询和预览采用一致账户版本的读取；分页不截断全量统计。容量超限整笔拒绝，不部分执行终态传播或裁剪历史和请求回执。

## 测试决策

- 主要业务验收边界为正式 HTTP 接口到真实数据库事务：提交命令、重新查询，并验证持久化事实、有效事件、奖励、版本和回执。只检查可观察行为，不锁定内部函数或组件树。
- 沿用现有 Worker HTTP 请求测试和浏览器测试入口；旧领域、单表存储及原型测试不作为新版通过证据。身份服务可使用受控测试身份，真实登录另作验证；事务、外键、权限和并发必须使用隔离数据库，不能把模拟持久化当作原子性证明。
- 数据库验证覆盖账户隔离、同 owner 外键、首次并发初始化、成功提交与中途失败回滚、版本冲突、同 key 重试、已失效回执查询、完成／取消竞争、达成／取消竞争、终态传播及总经验与事件一致。
- 计算测试只补必要临界值：19→20→19→20 经验、8 次行动加系数 2 后总经验 24、零行动固定 1、动态成就回退、计奖历史归属及跨午夜请求。
- 展示查询验证 2 项完成＋1 项待完成＋1 项结束得到 2／3，零分母显示空进度；独立任务在两种筛选中可见；统一终态开关、排序及历史详情不受隐藏影响。
- 浏览器覆盖创建、完成、取消、达成、改期、迁移、刷新持久化、预览过期、未知结果重试、命令成功后查询失败、切换账户、终态开关本地记忆，以及 390px 手机和键盘操作。
- 交付先密钥扫描，再接口、安全、类型、构建、浏览器及首页新闻回归，完成需求与规范双轴评审。运行证据区分模拟身份、真实数据库、浏览器和生产；打开本地预览供用户验收，具体 PR 获明确合并授权后再合并，部署 SHA 和生产隔离验证后关闭 Issue。
