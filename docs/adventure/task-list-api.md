# 今日聚焦日期任务列表（#145）

`POST /api/adventure/tasks/list` 是只读、需要现有访问账户身份的独立接口。查询条件只放 JSON 请求体，不接受 URL 查询参数；接口不执行搜索，不改变目标详情原有任务读取方式。

请求字段为 `date`（所选 YYYY-MM-DD）、`scope`（all／focus，默认 all）、`expectedVersion`（页面版本）、`today`（页面权威北京日期）、`page`（从 1 开始，默认 1，上限 1,000,000）。其他字段被拒绝，不能传 owner 或 search。

返回 `version`、`today`、`date`、`scope`、`page`、固定 `pageSize=10`、完整范围的 `total`、本批 `tasks` 和完整范围的 `progress={completed,total,ratio}`。零分母 ratio 为 null。每批 10 条为传输批量，前端完整加载后仍按每页 20 条呈现。任务说明与完成快照各最多 4000 字符；按 JSON 转义每字符最高 6 bytes、名称与固定元数据估算，10 条保守低于 1MB。每批仍保留现有 1MB 防御预算，超出明确返回容量错误，不能以截断代替完整结果。

过去按有效完成的实际完成日查询；未来按计划执行日查询 pending；今天包括计划日不晚于今天的 pending 和今天实际完成的 completed。过滤逻辑删除与已结束任务。聚焦范围继续包含聚焦目标任务与独立任务。排序先逾期待完成、今日待完成、已完成，再按计划日、创建时间和稳定 ID，创建日只作稳定排序，不决定日期归类。

#185 保留上述查询与分组：未来任务可提前完成，完成后归入实际操作当天并即时计入今日 progress，移出未来 pending；当天取消后恢复原未来计划。过去日期仍只读；今天和未来日期的圆钮按服务端能力启用，实际完成日过去后不可取消，即使计划日仍在未来。

现有目标分类四表库应用 `20261114020502_adventure_future_completion.sql` 更新完成资格、能力和预览；日期列表 RPC 本身不变。验证见 [提前完成验收](qa-future-completion.md)。

只读 RPC 在账户共享锁内核对 revision 和锁后取得的 Asia/Shanghai 当天；版本或当天与页面不符返回 409。所有批次要求同一账户、日期、scope 和版本。读取不初始化账户、不写事件、版本或成功回执，仅 service_role 可执行。

浏览器按批读取完整结果后再搜索名称／说明并统一每页 20 项显示；搜索、分页不改变 RPC 返回的完整范围进度。读取中仅显示加载数量；失败不展示部分任务，用户可显式重新读取页面和任务。日期切换、账户切换、版本变化时取消旧读取；迟到响应不能覆盖新视图。每批超时 15 秒，可随日期切换取消，不将大量任务压成单个无界响应。

空库先执行 `db/adventure/create-planning.sql`，再执行 `db/adventure/list-tasks.sql`。已有五表库只应用 `db/adventure/migrations/20261106200055_adventure_today_task_rules.sql`，该文件在同一事务包含任务规则、日期列表索引／RPC、权限及 PostgREST schema 刷新，不修改业务行，不能重复执行空库初始化或只摘取列表片段。生产升级由整份规格的授权与发布流程统一处理。
