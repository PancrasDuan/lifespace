# 今日聚焦日期任务列表（#145）

`POST /api/adventure/tasks/list` 是只读、需要现有访问账户身份的独立接口。查询条件只放 JSON 请求体，不接受 URL 查询参数；接口不执行搜索，不改变目标详情原有任务读取方式。

请求字段为 `date`（所选 YYYY-MM-DD）、`scope`（all／focus，默认 all）、`expectedVersion`（页面版本）、`today`（页面权威北京日期）、`page`（从 1 开始，默认 1，上限 1,000,000）。其他字段被拒绝，不能传 owner 或 search。

返回 `version`、`today`、`date`、`scope`、`page`、固定 `pageSize=50`、完整范围的 `total`、本批 `tasks` 和完整范围的 `progress={completed,total,ratio}`。零分母 ratio 为 null。每批响应受现有 1MB 预算限制，超出明确返回容量错误，不能以截断代替完整结果。

过去按有效完成的实际完成日查询；未来按计划执行日查询 pending；今天包括计划日不晚于今天的 pending 和今天实际完成的 completed。过滤逻辑删除与已结束任务。聚焦范围继续包含聚焦目标任务与独立任务。排序先逾期待完成、今日待完成、已完成，再按计划日、创建时间和稳定 ID，创建日只作稳定排序，不决定日期归类。

只读 RPC 在账户共享锁内核对 revision 和锁后取得的 Asia/Shanghai 当天；版本或当天与页面不符返回 409。所有批次要求同一账户、日期、scope 和版本。读取不初始化账户、不写事件、版本或成功回执，仅 service_role 可执行。

浏览器按批读取完整结果后再搜索名称／说明并统一每页 20 项显示；搜索、分页不改变 RPC 返回的完整范围进度。读取中仅显示加载数量；失败不展示部分任务，用户可显式重新读取页面和任务。日期切换、账户切换、版本变化时取消旧读取；迟到响应不能覆盖新视图。每批超时 15 秒，可随日期切换取消，不将大量任务压成单个无界响应。

安装时在五表基线之后应用日期列表 SQL；已有数据库只应用新增索引与 create-or-replace 函数片段，不能重复执行空库初始化。生产升级由整份规格的迁移与发布流程统一处理。
