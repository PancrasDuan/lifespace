# 07：归档规划并保留可追溯支线迁移

## Parent

https://github.com/PancrasDuan/lifespace/issues/53

## What to build

把不再推进的容器或目标归档并回看历史，或将支线升级新主线／迁入已有主线，在改名与迁移后仍能解释旧奖励来源。

## Acceptance criteria

- [ ] 归档确认展示关联目标任务待结算，取消无变化；取消聚焦，停止未完成及后续周期，历史只读。
- [ ] 归档不等于达成不发目标奖；已完成任务和已到期完整月次日仍结算且不重复；主线占5名额、支线释放在用。
- [ ] 两种支线迁移先原子校验5主线与目标主线3聚焦；保留原聚焦，无名额不挤掉别人也不自动取消。
- [ ] 成功保留目标任务周期身份与任务月积累，原支线退出在用保留只读来源，无恢复或降级入口。
- [ ] 失败或取消无任何半迁移状态或提前释放；并发迁移不能突破配额；冻结快照不被容器改名覆盖。
- [ ] 来源与历史可查看原完成标准、原日任务、停止／待结算／已结算状态及当前归属。
