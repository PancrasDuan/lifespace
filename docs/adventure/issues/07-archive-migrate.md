# 07：结束主线与目标并迁移可操作内容

状态：2026-10-20 本轮目标领域要求，待实现；既有检查不代表本版通过，奖励机制后续梳理。

## Parent

https://github.com/PancrasDuan/lifespace/issues/53

## What to build

实现终态向下锁定，以及目标和任务迁移的归属、聚焦、排序和历史边界。

## Acceptance criteria

- [ ] 普通主线仅由手动操作改变状态，下属为空或全达成／结束／迁出不自动结束；结束释放普通主线名额，独立区不能结束。
- [ ] 结束主线使进行中目标进入未达成终态，原已达成结果保留；全部下属任务只读，过去事实保留。
- [ ] 目标可达成或未达成而结束，两种终态都不可恢复或撤销，下属停止并锁定；第一版无目标删除。
- [ ] 进行中目标可跨主线或独立区迁移，身份保持、任务随行；先验源／目的状态和聚焦配额，满额先调整，失败或取消无部分改变。
- [ ] 迁移保留聚焦，落位目的同类组末尾，其他目标相对顺序不变。
- [ ] 可操作任务支持目标间及目标／独立身份迁移，保留身份和周期；普通主线不直接接收任务，终态不能迁出。
- [ ] 完成时归属及日期保持历史快照，迁移不把过去行动转给新目标，也不绕过其历史终态锁定。
- [ ] 终态默认隐藏、可手动显示及只读查看，已结束主线仍提供原目标历史入口；奖励结算留待后续讨论。
