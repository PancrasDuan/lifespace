# 07：结束主线、目标和任务并迁移可操作内容

状态：2026-10-20 本期一次性任务规范，待实现、重新验收；本次只更新本地文档，远端 Issue 尚未同步。

父规格：#53（https://github.com/PancrasDuan/lifespace/issues/53）。当前规则以 [规格](../spec.md) 为准。

## 要做的事

实现一次性任务结束与误建删除，以及主线／目标终态传播和归属迁移。

## 验收标准

- [ ] 普通主线仅手动结束，空主线或目标全完成／结束／迁出不自动结束；确认结束释放名额，独立区不能结束。
- [ ] 结束主线使进行中目标进入未达成终态，已达成及已完成事实保留，下属只读，终态不可恢复或迁出。
- [ ] 待完成任务手动确认结束后立即停止且不可恢复，取消确认无变化；已完成不转为未完成而结束。
- [ ] 仅尚未开始、从未产生完成、奖励或历史安排的误建任务可逻辑删除；已开始、有记录、已完成、已结束不能删除，曾完成后取消也不恢复删除资格。
- [ ] 进行中目标跨在用主线／独立区迁移，身份保持、任务随行、保留聚焦先验名额、目的同类组末尾落位，失败／取消无部分变化。
- [ ] 可操作任务跨目标或目标／独立身份迁移，任务与安排身份保留，普通主线不直接接收任务；历史归属和终态锁定不被迁移改写。
- [ ] 主线结束停止未入账奖励，已入账成果保留；其余奖励事务另议，不依赖延期周期票。
