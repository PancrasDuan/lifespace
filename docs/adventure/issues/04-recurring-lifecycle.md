## What to build

从周期管理暂停、恢复或结束，并从今天或未来修改频率、执行星期和结束日期，预览对未来安排和计划次数的影响。

## Acceptance criteria

- [ ] 暂停之前已到期的完整任务月资格保留，不被暂停状态撤销；实际奖励结算由票05验证，票04不依赖票05。
- [ ] 暂停不安排、不计计划，按实际暂停天数顺延任务月；多次暂停累计、同日暂停恢复0天。
- [ ] 恢复按原规则继续，不补造暂停活动，保留周期ID、历史、任务月、达标月和系数。
- [ ] 结束停止当天未完成与未来安排；保留完成、历史；所属主线未结束时保留完整到期月资格，主线结束后下属未入账奖励不再结算，残月不发奖；结束后只读，不重开。
- [ ] 修改从今天或未来生效，按版本分段计划，取消不保存；过去、已完成、已结算不变，未来旧规则撤下不删除历史。
- [ ] 未来重复规则调整展示前后执行日、计划数、完成率和奖励预览；已安排其他未来规则的替换行为明确。
- [ ] 生命周期及规则命令遵守expectedVersion与幂等journal；HTTP跨账户操作拒绝。主线或目标结束／目标达成组合验收归后续票。
