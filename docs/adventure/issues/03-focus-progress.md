## 要做的事

在页面聚焦及排序目标，切换聚焦／全部、日期和搜索，看到后端计算且不受分页截断的任务进度。

## 验收标准

- [ ] 只有进行中真实目标可聚焦，每普通主线最多 3 个、独立目标共用 3 个；不设全账户 3 个限制，inbox 不聚焦，未聚焦仍可执行任务。
- [ ] 后端返回先聚焦后未聚焦、各组沿用手动顺序的结果；拖动及键盘上下移动持久化，不改变目标身份、归属或聚焦状态，非法排序与并发配额失败无部分变化。
- [ ] 聚焦视图显示聚焦目标下任务及独立任务；全部视图显示全部目标任务及独立任务，两者继续受日期和搜索约束；独立任务不因没有目标而消失。
- [ ] 后端按当前归属及明确查询范围返回已完成／（待完成＋已完成），排除已结束、已删除及无效完成；2 项完成、1 项待完成、1 项结束为 2／3，零分母显示“暂无可统计任务”。
- [ ] 目标汇总不因任务列表分页截断；迁出内容不计当前目标进度，历史行动归属不由当前进度重算；完成或取消后重新查询进度，进度不自动达成目标。
- [ ] 浏览器演示聚焦配额、鼠标和键盘排序、双视图独立任务可见、日期与搜索组合及刷新回读；终态和迁移的跨功能组合在最终集成票重验，不把它们作为本票启动条件。
- [ ] 本票新增或修改的查询、预览及命令使用后端权威计算和校验；前端只负责输入、确认、提交、展示和重新查询，不自行计算业务结果或乐观修改事实。
- [ ] 命令携带 expectedVersion 和 requestId，事实、事件、账户汇总、版本及成功回执同事务；同 key 重试不重复执行，异命令拒绝，409 重读确认，结果未知保留原请求，已成功而查询失败只重试读取。
- [ ] 通过正式 HTTP 到隔离真实数据库验证本票业务及持久结果、失败回滚、账户隔离和必要并发；浏览器完成本票关键操作并刷新回读，不用旧单表、原型或模拟持久化证明本票通过。提供当前版本证据，按仓库要求先密钥扫描再完成相关检查。
