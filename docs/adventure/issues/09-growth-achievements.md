# 09：查看成长账本与十类成就完整证据

## Parent

https://github.com/PancrasDuan/lifespace/issues/53

## What to build

从顶部徽章或成长记录逐笔解释经验与成就，追踪原任务快照、计算过程、触发记录和长期周期进展。

## Acceptance criteria

- [ ] 每笔单次／目标／周期经验含来源、完成或到期日、结算日、金额、计算过程、对应任务快照和可选评价感想。
- [ ] 成就行动1/10/50/100、目标1/3/10、单周期达标月3/6/12共10类；次日自动解锁且无额外XP。
- [ ] 长期按周期分别判断、不合并不同任务月数；同类徽章合并，在详情列任务与月份，暂停或未达标不收回。
- [ ] 成就展示条件、当前进度、剩余差额、日期与关联触发账本；首次解锁来源稳定，多成就合并提示。
- [ ] 改名迁移归档不改结算快照，账户新数据不套原型72XP；缺失初始历史显式标注不虚构。
- [ ] XP账本合计、等级、累计行动、达成目标和每周期达标月完全可核对；分页不截断统计。
