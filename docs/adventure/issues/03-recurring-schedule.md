# 03：创建长期周期任务并查看完整排期

## Parent

https://github.com/PancrasDuan/lifespace/issues/53

## What to build

建立每天／每周指定星期周期规则，预览与查询今天和任意未来日期的安排，重新打开仍正确，离线超过28天后不漏计划。

## Acceptance criteria

- [ ] 开始日、可选包含当天的结束日、每日／周执行星期校验与排期预览一致。
- [ ] 稳定周期ID、规则版本与计划槽位，正常计划同周期同日唯一；规则计算完整月计划，不依赖28天实例截断。
- [ ] 周期单实例改期保留原计划槽位、slot ID、计划所属任务月；实际完成计执行日任务月，跨月不重写分母、不重新生成原槽，同action仅一次单次奖，额外完成无slot。
- [ ] 计划活动完成通过单次结算；周期与目标关联完整，来源标签可区分同主线不同目标。
- [ ] 任务月按原始起始日、月末回退、闰年跨年计算，区间及到期边界明确。
- [ ] 浏览器跨刷新与日期范围查询不重复生成；受控时钟测试多年月份和长时间未访问追赶。
