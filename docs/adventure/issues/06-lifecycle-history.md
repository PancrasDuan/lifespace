# 06：结束规划、删除误建任务并查看终态历史

状态：2026-10-22 已在交付工作树按本版实现并通过临时隔离数据库验证；Issue 仍待真实发布验收后关闭。

## 父规格

https://github.com/PancrasDuan/lifespace/issues/53

## 要做的事

确认结束主线、目标或待完成任务，删除符合条件的误建任务，并通过统一开关查看只读终态内容；已有成果保持不变。

## 验收标准

- [x] 普通主线只由手动确认结束，空主线及目标全达成／结束／迁出不自动结束；结束释放 5 条在用配额，独立区和 inbox 不能结束。
- [x] 目标未达成而结束及主线结束传播到当前下属 pending 任务，取消聚焦、释放名额并只读；已有目标达成及任务完成结果、经验和历史保留，终态不可恢复或迁出。
- [x] 待完成任务结束前由后端预览影响，确认后立即停止且不可恢复，取消无变化；已完成任务不改成未完成而结束，不新增结束奖励。
- [x] 误建删除仅限尚未开始且从未产生完成、奖励或历史安排的任务；执行日已到即不可删，仅首次未来安排不等同历史。曾完成后取消仍无删除资格，数据库逻辑隐藏、不物理删除。
- [x] “主线与目标”页统一“显示已达成／已结束”开关默认关闭，按账户保存在当前浏览器、刷新保留、不跨设备同步；切换账户不沿用另一个账户的设置。
- [x] 后端排序保留进行中优先、聚焦及手动顺序；终态目标在所属组末尾按终态时间倒序，已结束主线在主线列表末尾；隐藏不影响历史详情及成长来源访问。
- [x] 结束／删除后后端重新计算任务进度并排除相应任务，零分母为空；真实事务验证传播中途失败整笔回滚、重复请求、历史锁定及经验不变。
- [x] 浏览器演示停止一条含已达成和未完成内容的主线、独立任务结束、误建删除成功与拒绝、终态开关刷新记忆及只读查看。
- [x] 本票新增或修改的查询、预览及命令使用后端权威计算和校验；前端只负责输入、确认、提交、展示和重新查询，不自行计算业务结果或乐观修改事实。
- [x] 命令携带 expectedVersion 和 requestId，事实、事件、账户汇总、版本及成功回执同事务；同 key 重试不重复执行，异命令拒绝，409 重读确认，结果未知保留原请求，已成功而查询失败只重试读取。
- [x] 通过正式 HTTP 到隔离真实数据库验证本票业务及持久结果、失败回滚、账户隔离和必要并发；浏览器完成本票关键操作并刷新回读，不用旧单表、原型或模拟持久化证明本票通过。提供当前版本证据，按仓库要求先密钥扫描再完成相关检查。
