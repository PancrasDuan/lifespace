## What to build

建立普通主线、系统独立区、进行中目标与聚焦管理，保留账户隔离及持久提交边界。

## Acceptance criteria

- [ ] 最多 5 条在用普通主线；独立区固定、不占名额、不可结束，独立目标数量不限。
- [ ] 普通主线只通过目标挂任务；独立任务直接归属独立区。目标名称及完成标准必填、归属手选，不默认；无草稿、多阶段或目标删除。
- [ ] 进行中可修改名称和标准，取消不保存，修改不自动达成；空目标或下属全部完成／结束／迁出不自动改变上级状态。
- [ ] 仅进行中可聚焦，每主线最多 3 个、独立目标共用 3 个；聚焦在前、组内手动排序，排序不改聚焦，未聚焦仍正常推进，保留任务筛选。
- [ ] owner 隔离、CAS、expectedVersion、原 requestId 安全重试及禁止客户端整包写状态继续有效。
- [ ] 终态目标默认隐藏可手动显示，详情只读；已结束主线仍可查看目标历史；旧测试不代表新规则通过。
