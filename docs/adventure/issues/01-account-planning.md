# 01：创建主线与独立目标并持久保存

状态：2026-10-20 本期一次性任务规范，待实现、重新验收；本次只更新本地文档，远端 Issue 尚未同步。

父规格：#53（https://github.com/PancrasDuan/lifespace/issues/53）。当前规则以 [规格](../spec.md) 为准。

## 要做的事

建立普通主线、系统独立区、目标及聚焦管理，保持账户隔离与持久化。

## 验收标准

- [ ] 最多 5 条在用普通主线，独立区固定、不占名额且不能结束，普通主线仅通过目标挂任务。
- [ ] 目标名称、完成标准必填，归属手选；进行中可编辑，取消不保存，任务全完成或为空不自动达成；无目标删除、草稿或多阶段。
- [ ] 仅进行中可聚焦，每主线 3 个、独立目标共用 3 个；先聚焦后未聚焦、组内手动排序，不限制任务执行。
- [ ] 按 [数据库设计](../backend-database.md) 与 [业务逻辑](../backend-business-logic.md) 验证五张关系表、按需创建并复用的独立主线／inbox、同 owner 复合外键及不变量、账户 total_xp、账户级 revision、事务、expectedVersion 和原 requestId 安全重试；客户端禁止整包写状态。
- [ ] 终态目标默认隐藏、可手动显示，只读详情与已结束主线入口保留；旧测试不证明本版通过。

## 前置任务
