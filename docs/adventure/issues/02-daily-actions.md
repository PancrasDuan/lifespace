## 要做的事

创建目标任务或独立任务，完成当天行动即获得 1 点经验，可在允许时取消和再次完成；页面与刷新后的持久结果一致。

## 验收标准

- [ ] 名称、执行日期和目标／独立归属手选必填，说明可选，只有一次性任务。独立任务内部复用唯一 inbox，对外表达为无真实目标的独立身份，不计目标数量。
- [ ] 由服务端 Asia/Shanghai 确定当天；只完成当天安排，未来不可提前完成，过去不可补写，逾期仍待完成。提供今天／未来／过去的基础查询和可操作原因，不以浏览器时间校验。
- [ ] 待完成任务可编辑名称和说明，task_updated 事件保存前后内容及归属快照；已完成事实使用发生时内容，编辑不改历史，不产生奖励。
- [ ] 完成同事务提交任务状态、具体完成事件、1 点 reward_task、total_xp、revision 和回执，同一行动最多一条有效完成；保存完成时任务、主线、真实目标或独立身份及日期快照。
- [ ] 取消预览明确成长影响，仅完成当天且未被任务、当前或历史归属终态锁定时允许；按具体完成事件取消，原完成和任务奖励同时逻辑失效，数据库保留、界面及有效查询排除，不追加负数奖励。
- [ ] 取消 A、再次完成 B 后，旧取消 A 和旧完成请求重试不影响 B；跨日重试成功请求只回读既有回执，不能重新执行业务动作。
- [ ] 后端同时提供总经验、等级、本级进度、行动数及成就影响供页面反馈和取消预览；验证 19→20→19→20 经验的升级、回退及再次完成，不依赖成长记录票才能正确计奖。
- [ ] 浏览器演示目标任务和独立任务创建、编辑、完成、预览取消、再次完成与刷新；完整七个徽章、分页流水和筛选进度另由后续切片交付。
- [ ] 本票新增或修改的查询、预览及命令使用后端权威计算和校验；前端只负责输入、确认、提交、展示和重新查询，不自行计算业务结果或乐观修改事实。
- [ ] 命令携带 expectedVersion 和 requestId，事实、事件、账户汇总、版本及成功回执同事务；同 key 重试不重复执行，异命令拒绝，409 重读确认，结果未知保留原请求，已成功而查询失败只重试读取。
- [ ] 通过正式 HTTP 到隔离真实数据库验证本票业务及持久结果、失败回滚、账户隔离和必要并发；浏览器完成本票关键操作并刷新回读，不用旧单表、原型或模拟持久化证明本票通过。提供当前版本证据，按仓库要求先密钥扫描再完成相关检查。
