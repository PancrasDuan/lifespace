# 02：安排并完成当天任务，次日结算单次经验

## Parent

https://github.com/PancrasDuan/lifespace/issues/53

## What to build

在目标下创建一次性任务与检查清单，执行当天任务、撤销或编辑未来安排，次日刷新得到可追踪单次经验和等级反馈。

## Acceptance criteria

- [ ] 任务创建全局手选归属；目标内入口可预选；显示主线／支线名称与目标名称；关闭回原详情。
- [ ] 今天／未来／过去、聚焦／全部筛选与 dashboard 全部可执行口径一致且说明差异。
- [ ] 只有当天可完成撤销，当天和未来可编辑；过去服务端冻结，清单不计经验，未来不可提前完成。
- [ ] 每独立行动+1待结算经验，次日依据服务端日期结算；已结算重复刷新、并发请求、网络重试不双发。
- [ ] Lv.1从0XP开始，升级成本20+5×(L−1)，进度和跨级提示正确，级别不改变功能或倍率。
- [ ] 所有写入通过原子领域命令与唯一幂等键；持久账本保留来源与日期，正式接口拒绝客户端模拟日期。
