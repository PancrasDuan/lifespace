# 02：创建与执行一次性任务并取消完成

状态：2026-10-20 本期一次性任务规范，待实现、重新验收；本次只更新本地文档，远端 Issue 尚未同步。

父规格：#53（https://github.com/PancrasDuan/lifespace/issues/53）。当前规则以 [规格](../spec.md) 为准。

## 要做的事

建立一次性任务的内容、归属、日期、状态、有效完成及逻辑删除规则。

## 验收标准

- [ ] 名称、执行日期、目标／独立身份必填，说明可选；类型创建后不可转换，无周期、暂停、额外完成、清单或计划结束日期入口。
- [ ] 任务为待完成、已完成、已结束，逾期只是日期提示；服务端固定 Asia/Shanghai，只能完成当天安排，过去冻结、未来不可提前完成。
- [ ] 同一行动仅一条有效完成，保存当时 taskId、mainlineId、goalId、日期及内容来源快照；独立任务 goalId 为空。
- [ ] 仅完成当天且任务和当前／历史上级未终态锁定才可取消；完成记录逻辑删除、界面移除、业务统计排除，数据库保留，再次完成不重复计数。
- [ ] 完成、取消、再次完成及重试原子提交；旧取消请求重试不影响新完成，双击、多设备并发不重复业务动作。
- [ ] 待完成任务可改名称、说明；历史快照不改写。已完成和已结束只读，已完成仅保留符合条件的取消入口。
- [ ] 奖励记录删除、结算和成长重算待独立梳理，不将负数冲正作为要求。
