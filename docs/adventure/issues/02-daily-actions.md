# 02：执行当天任务与取消完成

状态：2026-10-20 本轮目标领域要求，待实现；既有检查不代表本版通过，奖励机制后续梳理。

## Parent

https://github.com/PancrasDuan/lifespace/issues/53

## What to build

按目标或独立身份组织任务与清单，验证日期、历史归属及上级终态锁定；奖励处理另议。

## Acceptance criteria

- [ ] 任务属于目标或独立区，普通主线不直接挂任务；归属手选，来源身份清楚。
- [ ] 当天且未锁定才可执行、取消完成；当天和未来可编辑，过去冻结，未来不能提前完成。
- [ ] 目标或主线终态后全部相关任务和完成记录只读，即使当天也不能取消，不能先撤目标或迁出绕过。
- [ ] 完成记录保存当时 mainlineId、goalId、taskId、日期；独立任务 goalId 为空，迁移不改历史。
- [ ] 取消完成不追加负数冲正，奖励记录删除与成长重算细节待后续讨论，不作为本轮验收范围。
- [ ] 重试与并发不重复业务动作，账户隔离、持久化及服务端权威日期保持有效。
