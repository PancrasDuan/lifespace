# 05：到期任务月与单次奖励原子合并结算

## Parent

https://github.com/PancrasDuan/lifespace/issues/53

## What to build

在主页面次日刷新看到到期完整任务月、单次奖励共同更新经验等级、达标月和长期系数，每次奖励可核对计算。

## Acceptance criteria

- [ ] R=min(实际/计划,1)，P0不计算率不发周期奖励不增达标月；超额仍保留实际次数。
- [ ] 完整月基础10XP；R≥80%才应用1.1^floor(此前达标月/3)，未达标用1但积累保留。
- [ ] 每完整月最多达标+1，累计不要求连续，每3个新档下月起生效；精确计算后每笔floor。
- [ ] 暂停前已到期完整任务月仍可正确结算，暂停只顺延当前未满月，不取消既有完整月资格。
- [ ] 多月未访问顺序追赶；完整到期月即使周期结束或归档仍结算；残月不结算。
- [ ] 三类来源模型可扩展且任务月唯一键防重；并发两结算、超时重试及事务失败不双发、不只更新部分累积。
- [ ] 周期管理展示当前任务月、计划／实际、达标月、当期和下期系数及历史；账本与顶部XP一致。
