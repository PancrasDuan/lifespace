# 05：任务月到期结算与长期奖励

状态：2026-10-19 当前验收要求，待实现；既有检查不代表本版通过。

## Parent

https://github.com/PancrasDuan/lifespace/issues/53

## What to build

在完整任务月到期后的首次打开或刷新中结算周期奖励，不额外等待次日。

## Acceptance criteria

- [ ] 满月日当天即可结算，按 [起点, 下一满月日) 统计；多月离线按月顺序追赶，无后台时钟或原型日期入口。
- [ ] R=min(实际/计划,1)，P=0 时率不适用、奖励零、不增达标月并保留解释记录。
- [ ] 完整月基础 10 XP，R≥80% 才应用 1.1^floor(此前达标月/3)，未达标用 1，积累不清零；精确计算后逐笔 floor。
- [ ] 每完整月最多增加 1 达标月，不要求连续；第 3 个达标月仍用旧系数，下一任务月才用 1.1。
- [ ] 所属主线未结束时，暂停前到期月及单独结束周期的资格保留既有独立规则；目标达成／结束后的未入账周期奖励待后续讨论，不由目标终态只读推导结算资格。主线结束后，下属所有尚未入账奖励停止结算，包括已到期但未入账的完整任务月；后续打开、刷新或离线追赶均不补发。已入账经验、等级、成就、达标月积累与流水保留，不因结束扣减。未入账奖励不推进达标月或成就。
- [ ] 月份唯一键、重复刷新、并发及未知结果重试不双发；XP、等级、成就与月份状态同次原子提交，不增加行动数。
- [ ] 展示计划、实际、完成率、达标月、累计及本期适用和下期系数，历史流水可核对；月末、闰年、跨年与暂停顺延有验证。
