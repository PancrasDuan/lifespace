# 06：按实际结果达成目标并决定周期去向

## Parent

https://github.com/PancrasDuan/lifespace/issues/53

## What to build

确认目标完成标准、选择系数并逐项决定周期继续或结束，次日合并单次、目标、到期任务月奖励。

## Acceptance criteria

- [ ] 任务全完成不自动达成；必须确认实际结果符合标准；系数1/2/3，跳过默认1，可选感想。
- [ ] 目标额外XP=冻结的独立行动实际完成次数×系数；计入合法已完成未结算记录，不计清单、重复行动。
- [ ] 每个运行或暂停周期均需手选继续／结束；继续保留归属、任务月、积累和原暂停状态。
- [ ] 继续活动从全部任务或周期管理执行；后续单次和任务月照常结算，原目标奖励冻结不追增。
- [ ] 结束停止后续并保留完整到期月；当天撤销目标达成不撤任务完成，生命周期去向可逆且不覆盖随后独立动作。
- [ ] 冻结目标确认后，撤销计入其中的当天任务前须先撤当天目标达成；撤目标只恢复确认前周期状态与选择，不强行恢复暂停、不重复排期、不丢确认后动作。
- [ ] 目标待结算当天可撤销，跨日冻结；同一目标只能结算一次；三类奖励总额、等级、统计一致。
