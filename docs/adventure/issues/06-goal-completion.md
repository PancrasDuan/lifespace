## 验收标准

- [x] 进行中真实目标可按完成标准手动达成，无任务或仍有未完成任务也允许；任务全部完成或为空不自动达成，inbox 永不达成。
- [x] 预览返回版本、规划日期、标准、有效计奖行动数 N、系数 1／2／3 的奖励及将停止的任务，默认／跳过评价取 1，感想可选；确认前提示需要继续的任务应先迁出，取消不改变业务数据。
- [x] 按完成当时 goal 归属、达成时仍有效且稳定任务身份去重的行动数计奖；N>0 奖励 N×系数，N=0 固定 1 点不乘系数。8 次行动选系数 2 后总经验为 24，零行动达成不增加行动数。
- [x] 目标终态、退出聚焦、下属 pending 任务结束、已有 completed 事实保留、唯一 goal_achieved 事件中的冻结奖励金额、计奖行动 ID、N、C、保底情况及评价／归属快照、total_xp、revision 和回执同事务提交；本票直接实现目标奖励，不推迟到成长记录票。
- [x] 同一目标只产生一次 goal_achieved，不追加独立奖励事件；历史读取冻结金额和依据。达成不可撤销、恢复、编辑、迁移或新增下属任务；下属全部只读，即使当天也不能取消完成。默认列表隐藏终态，详情可按稳定 ID 只读访问。
- [x] 预览后版本变化必须重读重新确认，不静默改奖励；真实事务验证达成与取消竞争、重复达成、失败回滚及既有奖励保留。
- [x] 浏览器演示有行动、零行动和仍有待完成任务的达成；统一终态显示开关在生命周期票完成，迁移组合与历史计奖联动在最终票重验。
- [x] 本票新增或修改的查询、预览及命令使用后端权威计算和校验；前端只负责输入、确认、提交、展示和重新查询，不自行计算业务结果或乐观修改事实。
- [x] 命令携带 expectedVersion 和 requestId，事实、事件、账户汇总、版本及成功回执同事务；同 key 重试不重复执行，异命令拒绝，409 重读确认，结果未知保留原请求，已成功而查询失败只重试读取。
- [x] 通过正式 HTTP 到隔离真实数据库验证本票业务及持久结果、失败回滚、账户隔离和必要并发；浏览器完成本票关键操作并刷新回读，不用旧单表、原型或模拟持久化证明本票通过。提供当前版本证据，按仓库要求先密钥扫描再完成相关检查。
