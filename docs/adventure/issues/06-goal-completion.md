## What to build

手动确认目标结果，统一终态并停止全部下属任务，不保留达成后继续或撤销达成路径。

## Acceptance criteria

- [ ] 名称、完成标准和归属有效；按实际结果手动确认，无任务或有未完成任务均可达成，任务全勾选不自动达成。
- [ ] 确认前展示将停止的任务和周期；需要继续的任务先迁出，取消确认不改变状态。
- [ ] 达成即已达成终态，运行及暂停周期、一切下属任务停止并只读，不提供继续周期选择。
- [ ] 目标达成和主线结束不能撤销，终态所有下属任务即使当天也禁止取消完成、编辑、执行或迁移。
- [ ] 终态自动取消聚焦、释放名额，默认隐藏可手动显示；详情保留标准、结果与历史。
- [ ] 第一版无多阶段目标、终态恢复或目标删除；奖励结算机制待后续讨论。
