# 成长记录与奖励来源验收（#62）

基线 `96957b7`；在 `codex/53-adventure` 交付工作树完成。仅使用临时 PostgreSQL／PostgREST 和受控测试身份，不读取或同步真实 Supabase，不推送、合并、部署或关闭 Issue。

## 操作与核对

| 场景与步骤 | 页面预期 | 数据库预期 |
|---|---|---|
| 进入成长记录或刷新 `?view=growth` | 全账户等级、本级进度、升级差额、总经验、行动数、成果数；全部七个成就保留 | 同账户共享锁内读当前版本；总经验等于所有有效完成／达成冻结 amount；不写事件或版本 |
| 完成任务，再查看成长流水和来源 | 显示固定1点、发生日、原内容／归属、稳定身份；安排历史可访问 | 只有 task_completed 内嵌奖励；流水、详情均读原事件，不重新发奖 |
| 有行动目标达成；无行动目标达成 | 分别显示 N×C、感想、冻结计奖行动；零行动固定1点 | 只投影 goal_achieved；计奖行动 ID、N、C、保底和来源快照不变 |
| 迁移、改名、结束主线后查看旧来源 | 保留发生时名称／归属；隐藏终态仍能通过永久链接和刷新访问 | 不联结当前归属替换历史，按 owner＋事件ID读取冻结 snapshot |
| 19→完成第20次→取消→再次完成 | 等级1→2→1→2，流水20→19→20；最后一条为新的完成 | 旧完成逻辑失效但保留，取消精确关联 completionId，新完成新ID；total_xp同步 |
| 100次行动、10个成果；取消一个合法完成 | 七项全部点亮，取消后百次行动不再点亮、还差1次 | 无成就经验、解锁行或解锁日期，实时计数100→99，其余条件不受影响 |
| 超过10条流水、超过5条目标计奖来源 | 流水加载更多、来源独立翻页，无重复缺漏；总统计不随页缩小 | 按版本＋事件游标读下一页；目标冻结来源按原数组分页 |
| 来源／分页临时失败后重试 | 已读流水保留；失败部分独立重试；无重复写入 | 只执行读 RPC，无命令／版本／奖励变化 |
| 别的会话写入后加载下一页 | 409提示重新读取成长记录；不混合新旧页 | 版本严格校验；并发读取只见同一版本的统计和有效事件 |
| 越权、无效游标、异常汇总 | 内容不存在或不可用，不暴露数据库原文 | owner隔离、RLS、函数权限有效；经验汇总不一致拒绝返回 |


真实数据库用例：`tests/api/adventure-growth-database.test.ts`、`tests/browser/adventure-growth-database.spec.ts`；只读、权限与索引SQL探针：`tests/database/adventure-growth.sql`。所有探针回滚，临时数据库由测试运行器销毁。
