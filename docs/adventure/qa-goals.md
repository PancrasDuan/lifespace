# #59 目标达成、冻结奖励与终态锁定验收

日期：2026-10-22。分支 `codex/53-adventure`，评审基线 `a4ccf09`。仅使用本机新建临时 PostgreSQL／PostgREST，业务运行正式 Worker HTTP 与数据库函数；Auth 使用受控身份，不访问现有 Supabase 验收库。

## 实现与验证边界

- 手动依据完成标准达成真实进行中目标，默认系数 1、感想可选；无任务或仍有待完成任务均可。inbox 和终态目标拒绝。
- 预览持账户共享锁，无写入，返回版本、日期、标准、三档冻结计奖预期及将停止任务，提示继续任务先迁出；旧版本不能确认或静默重算，前端必须重新预览。
- 按有效 task_completed 的历史 goal_id、稳定 task_id 去重计数。N>0 奖励 N×C，N=0 固定 1；只写一条 goal_achieved，冻结金额、行动 ID、N、C、保底、感想和来源快照。总经验、版本和回执同事务维护。
- 达成不可撤销，退出聚焦，下属未删除 pending 任务结束，completed 事实和奖励保留；下属全部只读，当前或历史归属终态均禁止取消。默认列表隐藏终态；永久链接按稳定 ID 同版本读取冻结结果、标准和分页任务历史。
- SQL 回滚探针覆盖当前归属变化不改历史计奖、失效记录排除、历史／当前终态锁定、唯一达成索引、失败整笔回滚、已删除任务不传播、函数权限。迁移仅作事务回滚夹具，不宣称 #60 已实现。
- 真实 HTTP 覆盖 8 次行动×系数 2 得 16 点目标奖励／24 点总经验、零行动三档保底、成就和等级、稳定详情、分页、失败无变化、账户隔离、版本冲突、达成与取消竞争、历史幂等回执。
- 1440px／390px 浏览器验证有行动且有待完成任务、取消预览、选择评价及感想、零任务保底、终态只读及永久链接刷新，并核对数据库事实；模拟响应只补未知结果重试、成功后查询失败和重新预览的恢复交互。
