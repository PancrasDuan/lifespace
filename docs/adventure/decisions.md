# 人生冒险默认决策

本文件保留当前有效选项、选择与理由。2026-10-20 已同步本轮目标领域结论，奖励结算机制留待后续讨论，本次仅更新规范，不授权恢复实现；涉及新规则的选择均待实现和重新验收。具体 PR 合并仍遵守仓库确认门禁。领域与持久层细化分别见 [领域选择](decisions-domain.md) 和 [后端选择](decisions-backend.md)，验收证据见 [覆盖记录](coverage.md)。

## D01 模型调度

- 备选：DeepSeek Flash；继承默认编程模型；另找外部模型服务。
- 选择：继承默认模型实现，gpt-6-astra review。
- 理由：当前可调度模型无 DeepSeek Flash，不读写外部模型密钥。
- 状态：已明确。

## D02 正式页面

- 备选：A 工作台；B 待办；C 地图。
- 选择：A 工作台，页面名称人生冒险。
- 理由：用户目前持续在 A 体验；已确认收敛组织最接近 A。仅做可恢复默认，不同时实现三套正式 UI。
- 状态：默认。

## D03 存储

- 备选：Supabase 全关系表／事务 RPC；Supabase 独立账户状态行＋版本 CAS；新增 D1；浏览器本地存储。
- 选择：现有 Supabase 独立 adventure_states(owner_id PK, state jsonb, version bigint)，Worker 严格领域命令与 PostgREST owner＋version PATCH CAS，初始化 ignore-duplicates，客户端不得整包写状态。
- 理由：复用现有服务、无需新增运行时或大规模 RPC 权限；整账户状态单行原子提交可同时约束奖励、配额、聚焦与迁移；普通命令冲突返回409，仅refresh有限重读重算，不能最后写覆盖。
- 状态：主 agent 已核对并冻结本期默认。

## D04 隔离

- 备选：沿用共享展示数据；新模块按账户隔离。
- 选择：新模块按 verified user id 隔离。
- 理由：新模块是个人可写成长数据；沿用共享只读任务会改变另一人的奖励。原有首页共享数据不变。
- 状态：默认已由主 agent 冻结。

## D05 测试 seam

- 备选：组件内部函数；领域命令；HTTP 全覆盖。
- 选择：领域命令主 seam，HTTP 隔离与关键浏览器路径补充。
- 理由：以最高稳定边界验证状态、持久事务和用户行为，避免围绕单文件原型复刻测试。
- 状态：默认。

## D06 时区

- 备选：随地区变化；浏览器随设备；账户固定时区。
- 选择：固定账户规划时区，初始 Asia/Shanghai。
- 理由：避免天气切城市或设备旅行把历史重新分日；服务端权威日期。主 agent 已明确与首页地区独立。
- 状态：本期默认，独立于首页有效地区。

## D07 结束与达成

- 选择：目标为进行中、已达成终态、未达成而结束终态。达成即结束并停止全部下属一次性／周期任务；继续任务应先手动迁出。
- 规则：目标按完成标准手动确认，无任务或有未完成任务也可达成；下属全完成、全迁出或为空均不自动改变目标或主线。手动结束普通主线使其进行中目标及全部任务停止，原达成及完成事实保留。终态不可撤销、恢复、编辑或迁出，即使当天也锁定完成记录；第一版不删除目标、不做多阶段。取消确认不改变状态。
- 理由：统一结束向下传播的含义，使目标成果与停止推进有明确边界。
- 状态：已确认，待实现；奖励结算不由终态操作权限推导。

## D08 周期单实例改期

- 备选：禁止改期；随执行日移动计划分母；保留原计划槽位、实际按执行日。
- 选择：保留原计划槽位、slot ID 和计划所属任务月，实际完成计入执行日期所属任务月；跨月不移动分母、不重新生成原槽，同 action 仅一次单次奖，额外完成无计划槽位。
- 理由：重复规则编辑才改未来计划；未选择随执行日移动分母，是为避免历史分母漂移并保留计划责任。执行日计实际真实反映投入日期，两种口径在详情中明确显示。
- 状态：主 agent 已冻结本期默认，不再待核验。

## D09 实时奖励与当天撤销

- 选择：只有当天且未被相关目标或主线终态锁定的任务完成可以取消；目标达成与主线结束不能取消。
- 规则：取消任务完成不追加负数冲正，采用删除对应奖励记录的方向；具体记录删除、重算、原子提交与去重边界后续讨论。本轮不新增奖励结算决策。
- 理由：目标为不可恢复终态，不能再要求先撤目标才能撤任务，也不能借迁移绕过历史锁定。
- 状态：目标操作边界已确认，奖励机制待独立梳理。

## D10 目标终态下的周期任务

- 选择：目标达成时不提供周期继续选项，运行与暂停周期均随目标停止并只读。
- 规则：需要继续的任务在目标确认终态前手动迁出，保留其身份和原运行／暂停状态；确认后不得迁出或恢复。
- 理由：所有下属任务统一遵守目标终态，避免暂停周期成为例外。
- 状态：已确认，待实现。

## D11 滚动排期

- 备选：固定 28 天；无限预创建；规则按需实体化／查询。
- 选择：规则按需实体化或查询并支持追赶。
- 理由：原型 28 天只是演示；正式完整月统计基于版本化规则，任何未访问月份不能漏结算。
- 状态：默认已由主 agent 冻结。

## D12 到期触发

- 选择：任务和目标奖励随相应业务命令实时提交；GET 只读取／初始化，页面 POST refresh 追赶具有资格的到期完整任务月，排除已结束主线下全部未入账奖励。
- 规则：任务月满月当天首次打开或刷新即可结算，不等待次日；按历史月份顺序追赶，不增加后台定时器，客户端不能指定日期。
- 理由：周期完成率需完整月才能确定，单次和目标奖励无需延迟；统一服务端日期、幂等与原子提交。
- 状态：用户已确认，待实现；旧验证证据不能证明新触发时机。

- 选择：保留原型独立推演，正式接口禁止模拟数据。
- 理由：已确认推演不影响主页面；不把模拟 72 XP 写入真实账户。

## D15 暂停与已有到期月份

- 备选：暂停阻止全部周期结算；仅暂停当前未满月和后续安排。
- 选择：所属主线未结束时，暂停前已到期完整月仍可结算，当前未满月按暂停天数顺延；主线结束后按 D07 停止下属所有未入账奖励。
- 理由：暂停不取消已经达成完整周期的奖励资格，避免状态操作取消已到期完整月的奖励资格。
- 状态：主 agent 与 Astra review 已明确。

## D16 版本冲突与命令幂等

- 备选：所有冲突自动重算；最后写覆盖；普通变更明确版本失败、结算有限重算。
- 选择：普通创建、编辑、规则、排序等用户命令带 expectedVersion，失配 409，不重放旧视图意图；仅刷新结算可有限 CAS 重算。owner＋requestId journal 保存 payload 摘要和稳定结果，与 state 原子提交；同 key 异 payload 拒绝，未知结果用原 key 重试。响应给最新 state＋稳定 command 结果，客户端按版本避免倒序回写。
- 理由：防止多标签页修改被旧视图悄悄覆盖，兼顾安全重试和结算幂等。
- 状态：主 agent 与 Astra review 已冻结。

## D17 数据库直接权限

- 备选：浏览器 JWT 直连；仅 Worker service_role。

- 理由：复用现有鉴权网关，不把完整个人状态或通用写权限扩大给浏览器；服务端 verified owner 是唯一授权来源。
- 状态：主 agent 与 Astra review 已冻结。

## D19 独立目标、聚焦与迁移

- 选择：普通主线只通过目标挂任务；系统独立区固定存在、不可结束且不占 5 条普通主线名额，承载数量不限的独立目标及独立任务，界面仍显示独立身份。
- 规则：聚焦只适用于进行中目标，影响展示顺序和任务筛选；每普通主线最多 3 个，独立目标共用 3 个，终态自动取消。先聚焦后未聚焦，组内保留手动顺序。目标创建名称、完成标准必填，归属手选，修改不自动达成。
- 迁移：目标在独立区与在用普通主线间及跨主线迁移，下属任务随行；保留聚焦且先校验名额，满额先调整。迁入目的同类组末尾，失败或取消不变；任务可在目标与独立身份之间及跨目标迁移。历史身份、日期和归属不随迁移改写。
- 理由：统一承载与迁移关系，同时避免普通主线跳过目标直接挂任务。
- 状态：已确认，待实现；第一版无目标删除、草稿或多阶段。

## D20 暂停当天纠错

- 选择：暂停周期在未被终态锁定时仍可取消当天完成，但不能新增完成或执行清单；结束后全部只读。
- 理由：取消完成不等于恢复排期，目标终态始终优先。
- 状态：操作边界保留；取消完成的奖励记录处理按 D09 后续梳理，不要求负数冲正。

## D21 聚合容量

- 备选：无界行；自动裁剪历史或journal；完整候选行限定预算。
- 选择：完整候选行按UTF-8限制8,000,000 bytes；超限拒绝且不发PATCH，原行可读，journal与历史不裁剪。
- 理由：为Worker解析及克隆保留余量，自动裁剪会破坏幂等与来源追溯；有限容量不是无限历史保证。
- 状态：边界回归已记录于后端验证；128MB真实Worker接近预算内存峰值尚未证明。
