# 人生冒险默认决策

本文件保留当前有效选项、选择与理由。用户授权按默认值推进；具体PR合并仍遵守仓库确认门禁。领域与持久层细化分别见 [领域选择](decisions-domain.md) 和 [后端选择](decisions-backend.md)，验收证据见 [覆盖记录](coverage.md)。

## D01 模型调度

- 备选：DeepSeek Flash；继承默认编程模型；另找外部模型服务。
- 选择：继承默认模型实现，gpt-6-astra review。
- 理由：当前可调度模型无 DeepSeek Flash，不读写外部模型密钥。
- 状态：已明确。

## D02 正式页面

- 备选：A 工作台；B 待办；C 地图。
- 选择：A 工作台，页面名称人生冒险。
- 理由：用户目前持续在 A 体验；已确认收敛组织最接近 A。仅做可恢复默认，不同时实现三套正式 UI。
- 状态：默认。

## D03 存储

- 备选：Supabase 全关系表／事务 RPC；Supabase 独立账户状态行＋版本 CAS；新增 D1；浏览器本地存储。
- 选择：现有 Supabase 独立 adventure_states(owner_id PK, state jsonb, version bigint)，Worker 严格领域命令与 PostgREST owner＋version PATCH CAS，初始化 ignore-duplicates，客户端不得整包写状态。
- 理由：复用现有服务、无需新增运行时或大规模 RPC 权限；整账户状态单行原子提交可同时约束奖励、配额、聚焦与迁移；普通命令冲突返回409，仅refresh有限重读重算，不能最后写覆盖。
- 状态：主 agent 已核对并冻结本期默认。

## D04 隔离

- 备选：沿用共享展示数据；新模块按账户隔离。
- 选择：新模块按 verified user id 隔离。
- 理由：新模块是个人可写成长数据；沿用共享只读任务会改变另一人的奖励。原有首页共享数据不变。
- 状态：默认已由主 agent 冻结。

## D05 测试 seam

- 备选：组件内部函数；领域命令；HTTP 全覆盖。
- 选择：领域命令主 seam，HTTP 隔离与关键浏览器路径补充。
- 理由：以最高稳定边界验证状态、持久事务和用户行为，避免围绕单文件原型复刻测试。
- 状态：默认。

## D06 时区

- 备选：随地区变化；浏览器随设备；账户固定时区。
- 选择：固定账户规划时区，初始 Asia/Shanghai。
- 理由：避免天气切城市或设备旅行把历史重新分日；服务端权威日期。主 agent 已明确与首页地区独立。
- 状态：本期默认，独立于首页有效地区。

## D07 结束后重开

- 备选：重开原周期；创建新周期。
- 选择：结束只读，需要新建周期。
- 理由：最接近已演示原型，避免结束和冻结结算边界被重开重算；新周期从零达标月，旧积累仍可回看。
- 状态：默认。

## D08 周期单实例改期

- 备选：禁止改期；随执行日移动计划分母；保留原计划槽位、实际按执行日。
- 选择：保留原计划槽位、slot ID 和计划所属任务月，实际完成计入执行日期所属任务月；跨月不移动分母、不重新生成原槽，同 action 仅一次单次奖，额外完成无计划槽位。
- 理由：重复规则编辑才改未来计划；未选择随执行日移动分母，是为避免历史分母漂移并保留计划责任。执行日计实际真实反映投入日期，两种口径在详情中明确显示。
- 状态：主 agent 已冻结本期默认，不再待核验。

## D09 目标撤销与继续去向

- 备选：仅撤奖励不恢复生命周期；恢复此次达成前生命周期。
- 选择：当天撤销恢复本次达成引起的生命周期变化。
- 理由：达成当天可撤销应可逆；先恢复确认前 running／paused／ended 状态与选择，不强行恢复暂停或重复排期，不丢确认后动作。冻结目标确认后撤其中任务须先撤当天目标达成，其他合法动作不得盲目覆盖。
- 状态：主 agent 已确认组合边界。

## D10 暂停状态目标达成选择继续

- 备选：自动恢复；保留暂停。
- 选择：保留暂停。
- 理由：继续表示周期仍被保留，不等于替用户恢复；运行周期继续运行，暂停周期继续暂停。
- 状态：默认。

## D11 滚动排期

- 备选：固定 28 天；无限预创建；规则按需实体化／查询。
- 选择：规则按需实体化或查询并支持追赶。
- 理由：原型 28 天只是演示；正式完整月统计基于版本化规则，任何未访问月份不能漏结算。
- 状态：默认已由主 agent 冻结。

## D12 次日触发

- 备选：浏览器自报结算日期；GET读取时结算；读回后POST refresh；定时后台。
- 选择：GET只读取／初始化个人状态，页面随后POST `refresh`命令，由服务端Asia/Shanghai日期惰性追赶昨天及更早的未结算记录。
- 理由：读接口不承担结算副作用，统一命令边界仍能安全处理重复进入或多设备刷新；不依赖新增cron，客户端不能选择结算日期。
- 状态：当前接口和页面实现一致。

## D13 原型独立推演

- 备选：移入正式写页面；原型独立保留。
- 选择：保留原型独立推演，正式接口禁止模拟数据。
- 理由：已确认推演不影响主页面；不把模拟 72 XP 写入真实账户。
- 状态：默认。

## D14 验收合并

- 备选：泛化授权自动合并；本地验收后请求具体 PR 确认。
- 选择：遵守具体 PR 合并确认。
- 理由：仓库 git-workflow 有明确门禁。完成开发、检查与可审阅预览后，确认是最后一步。
- 状态：强制门禁。

## D15 暂停与已有到期月份

- 备选：暂停阻止全部周期结算；仅暂停当前未满月和后续安排。
- 选择：暂停之前已到期的完整任务月仍先结算；当前未满月按暂停天数顺延。
- 理由：暂停不取消已经达成完整周期的奖励资格，避免状态操作截断待结算历史。
- 状态：主 agent 与 Astra review 已明确。

## D16 版本冲突与命令幂等

- 备选：所有冲突自动重算；最后写覆盖；普通变更明确版本失败、结算有限重算。
- 选择：普通创建、编辑、规则、排序等用户命令带 expectedVersion，失配 409，不重放旧视图意图；仅刷新结算可有限 CAS 重算。owner＋requestId journal 保存 payload 摘要和稳定结果，与 state 原子提交；同 key 异 payload 拒绝，未知结果用原 key 重试。响应给最新 state＋稳定 command 结果，客户端按版本避免倒序回写。
- 理由：防止多标签页修改被旧视图悄悄覆盖，兼顾安全重试和结算幂等。
- 状态：主 agent 与 Astra review 已冻结。

## D17 数据库直接权限

- 备选：浏览器 JWT 直连；仅 Worker service_role。
- 选择：仅 Worker service_role 访问 adventure_states，anon／authenticated 直接读取、插入、修改、删除全部拒绝，真实权限验证。
- 理由：复用现有鉴权网关，不把完整个人状态或通用写权限扩大给浏览器；服务端 verified owner 是唯一授权来源。
- 状态：主 agent 与 Astra review 已冻结。

## D18 原型捕获与实施基线

- 备选：直接把原工作区所有脏变更带入实施；捕获原型独立来源并从生产基线建立功能分支。
- 选择：原型 `codex/adventure-prototype-source@eee88c38f273da3e8d4aad3b7c43b9275fb781b8` 作为主证据；正式交付 `codex/53-adventure` 从 `origin/main@b816cafa402136e5a173ae046a2fc8cf5ca22127` 开始。
- 理由：保留原型证据及其他未提交内容，不把独立调研或认证变更混入人生冒险交付；远端main已读回核实一致。
- 状态：功能分支已创建；提交与PR按用户授权推进，具体合并和发布验收仍有独立门禁。

## D19 已达成支线迁移

- 备选：一律拒绝已达成支线；允许未归档支线保留身份迁移。
- 选择：已达成但未归档的支线允许升级新主线或迁入已有主线；归档内容禁止迁移。
- 理由：同一goal、task、cycle身份及历史奖励冻结，不因迁移重算，可安全保留已完成探索的来源；一律拒绝会限制已有成果归入长期方向。原有配额和聚焦校验继续执行。
- 状态：已实现，领域验证包含两条迁移路径。

## D20 暂停当天纠错

- 备选：先恢复周期再撤完成；暂停时允许当天撤销完成。
- 选择：暂停周期可以撤销当天未结算完成；暂停仍禁止新完成和清单执行，结束与归档继续只读。
- 理由：纠错不等于恢复安排，不应要求为撤一次误操作改变周期状态；只读历史和跨日冻结保持。
- 状态：已实现并有领域回归。

## D21 聚合容量

- 备选：无界行；自动裁剪历史或journal；完整候选行限定预算。
- 选择：完整候选行按UTF-8限制8,000,000 bytes；超限拒绝且不发PATCH，原行可读，journal与历史不裁剪。
- 理由：为Worker解析及克隆保留余量，自动裁剪会破坏幂等与来源追溯；有限容量不是无限历史保证。
- 状态：边界回归已记录于后端验证；128MB真实Worker接近预算内存峰值尚未证明。
