# 领域命令验收

状态：2026-10-19，功能分支 codex/53-adventure。仅覆盖纯领域命令边界，真实持久化、HTTP 身份隔离、浏览器及部署证据由对应验收补充，不能以此表替代。

## 接口

- `src/shared/adventure/index.ts`：稳定公开入口。
- `executeCommand(state, command, {today, now, idFactory?})`：失败不改输入，成功返回新 state 和结果；权威日期由 Worker 提供，版本与 requestId journal 由持久层原子处理。
- `queryTasks(state, from, to)`：按规则与暂停区间完整计算稳定计划槽，合并已存实例，不持久化窗口、不依赖 28 天。
- `cycleMonth`／`calculateCycleReward`：完整任务月与有理精度奖励投影。
- `taskCapabilities`／`commandCapability`：复用同一领域校验，不在 UI 重写状态规则。
- `forecastCycleChange`：正式 editCycle 命令的纯试算；前后使用首个受影响任务月的同一 index，已过滤停止和已重新安排实例。

## 当前证据

执行：Node 24.19.0；`npx vitest run tests/api/adventure-domain.test.ts`，**30 项通过**；`npm run typecheck` 通过。红绿日志位于工作区 `.scratch/adventure-delivery/domain-red-01.log` 至 `domain-red-18.log` 及对应 green 文件；各切片先验证行为失败再实现，不以最后绿色掩盖先前缺口。

| 领域行为 | 测试中的独立验收例 |
|---|---|
| 规划、编辑、聚焦、排序 | 初始零数据；主线 5／支线 10／每主线聚焦 3；反转目标顺序不改聚焦；失败输入完全不变 |
| 当日行动、检查清单、次日账本 | 当天待结算／撤销；未来不能完成、过去不能编辑；清单不发奖；重复刷新只留单笔 |
| 稳定槽与任意排期 | 1/31→2/28→3/31；60 天查询；改期不移动原分母，实际按执行月；非规范日期后缀不得伪造第二个 slot |
| 月奖励 | P0 不适用；79%／80%；超额封顶；Q=3／6；1.21 精确取整；3 个月 10、第四月 11；非连续达标保留 |
| 时间与暂停 | 闰年跨年；同日恢复 0 天；多次暂停；跨十余月长暂停不截断；暂停前完整月资格保留；残月结束不奖励 |
| 重复规则 | 未来指定日分段；过去完成保留；替换后续预约；首个受影响月份预览与正式命令一致 |
| 目标冻结与撤销 | 逐项去向；含未结算行动；继续周期不追增原目标奖；先撤目标才能撤冻结行动；恢复原暂停，不覆盖其后独立动作 |
| 归档与来源 | 只停止今天未来；昨天漏做记录冻结；已完成仍结算；迟到自然结束不回写过去；迁移保同 goal/cycle 和 sourceGoalId |
| 配额恢复与已达成迁移 | 支线达成释放名额后撤销重新校验 10 上限；满额失败全状态不变；已达成未归档支线两种迁移冻结奖不重算 |
| 额外完成与重新安排 | 来源链清单重置、同 action 不重复安排；额外当天撤销恢复不增 P，也不占正常计划槽 |
| 成就与经验 | 12 月双周期分别解锁 3／6／12；104 次行动＋276 周期 XP＝380，Lv.10、20/65；每徽章关联真实账本 |
| 安全与纯预览 | 严格 schema 拒绝 owner／XP／任意 state；非法日期为 DomainError；能力与预览均不改源 state |

暂停周期允许当天纠错撤销；结束与归档仍只读。目标撤销配额、迟到结束的历史冻结和已达成支线迁移均有专门回归。新增默认及备选理由见 `decisions-domain.md`。
