## 接口

- `src/shared/adventure/index.ts`：稳定公开入口。
- `executeCommand(state, command, {today, now, idFactory?})`：失败不改输入，成功返回新 state 和结果；权威日期由 Worker 提供，版本与 requestId journal 由持久层原子处理。
- `queryTasks(state, from, to)`：按规则与暂停区间完整计算稳定计划槽，合并已存实例，不持久化窗口、不依赖 28 天。
- `cycleMonth`／`calculateCycleReward`：完整任务月与有理精度奖励投影。
- `taskCapabilities`／`commandCapability`：复用同一领域校验，不在 UI 重写状态规则。
- `forecastCycleChange`：正式 editCycle 命令的纯试算；前后使用首个受影响任务月的同一 index，已过滤停止和已重新安排实例。
