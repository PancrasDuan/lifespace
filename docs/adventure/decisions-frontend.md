# 人生冒险前端约束

状态：2026-10-20 本期一次性任务及目标规则，待实现；旧原型和浏览器测试不能证明本版通过。本次只更新文档。

| 事项 | 当前选择 |
|---|---|
| 页面 | 采用 A 工作台，保留像素角色、紧凑经验条、右侧统计和成就横排；主内容为概览、主线与目标、成长记录，无演示切换器。 |
| 创建 | 主线、目标、一次性任务统一入口；归属明确手选。任务包含名称、可选说明和执行日期，无周期、暂停、额外完成、清单或计划结束日期入口。 |
| 任务状态 | 显示待完成、已完成、已结束；逾期只是日期提示。已完成结果保留，终态只读。 |
| 完成与取消 | 共享服务端操作能力校验；仅当天可完成／取消，记录取消后界面移除、不展示反复纠错过程；有效进度随服务端结果更新。 |
| 改期 | 待完成任务改到今天或未来，漏做保留来源；已完成先合法取消再改期。 |
| 结束与删除 | 结束先展示影响并确认；误建删除严格按服务端资格展示。已开始、有记录、已完成或已结束不能删除。 |
| 进度条 | 按有效完成事实展示，不设达标比例，不自动达成目标；汇总分母和已结束任务口径待确认。 |
| 聚焦与排序 | 仅进行中可聚焦，每主线 3 个、独立目标共用 3 个；先聚焦后未聚焦、组内手动排序，不限制执行。 |
| 迁移 | 目标连同任务迁移，保留聚焦先验名额，落位目的同类组末尾；任务可更换目标或独立身份，历史不改写。 |
| 终态与查看 | 达成或结束先确认影响范围，需继续的任务先迁出。成功后全部下属只读；终态目标默认隐藏，可手动显示，只读详情及已结束主线入口保留。 |
| 账户切换 | owner 改变时撤销旧 verified scope、页面和请求；新页面重新在线验证，不让旧表单以新账户写入。 |
| 写入与重试 | 普通命令不自动重放；未知结果保留内存中的原 requestId、expectedVersion 和 command 显式重试；409 先读取后重新确认，按版本防倒序覆盖。 |
| 超时 | 请求最多等待 15 秒，未知结果可重试；不把个人命令持久化到共用设备，刷新不自动重建操作。 |
| 小屏与键盘 | 390px 保留全部本期能力，无横向溢出；弹窗支持 Escape、Tab 焦点约束与关闭后焦点恢复。 |

历史完成内容按当时快照显示；逻辑删除记录不进入列表、次数、进度或有效成果展示。奖励反馈随独立奖励机制确认，不恢复目标撤销或负数冲正入口。旧测试的日期及覆盖范围见 [前端验收](qa-frontend.md)，本版须重新验证。
