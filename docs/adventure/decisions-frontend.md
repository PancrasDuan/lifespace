# 前端实现的默认选择

用户已明确授权进入正式开发交付，并要求记录备选、选择和理由。以下选择仅涉及正式页面与浏览器客户端；数据归属、经验与奖励仍由服务端验证。

| 事项 | 备选 | 当前选择与理由 |
| --- | --- | --- |
| 页面组织 | 原型 A／B／C；同时保留三套正式布局 | 采用 A 工作台：像素角色、紧凑经验条、右侧统计、成就横排；主内容分概览、主线与支线、成长记录。避免把演示切换器带入正式页面。 |
| 像素资产 | 重新生成；复用已确认角色 | 只复用原型来源中的 PNG 角色，使用独立组件与样式；未复制原型巨型 TSX、模拟数据或时间旅行入口。 |
| 账户切换 | 仅在新账户通过 `/me` 后更新 key；立刻撤销旧页面与请求 | SDK owner 改变时同步撤销旧 verified scope，旧页面卸载。新页面必须重新在线验证；读写还绑定页面 verified owner，取 SDK 会话及 GET 刷新会话后再次比对。防止旧表单携带新账户 token 写入。客户端 owner 仅作本地一致性检查，不进入业务命令，服务端身份仍是唯一授权来源。 |
| 写入失败 | 自动重发新命令；自动覆盖；保留原请求显式重试 | 写请求不自动重放。结果未知时保留原 requestId／expectedVersion／command，在页面内安全重试；409 要求重新读取并确认，不能悄悄覆盖旧视图意图。 |
| 超时与待重试数据 | 无限等待；浏览器持久保存个人命令；有限等待并仅保留内存 | 请求最多等待 15 秒，超时视作结果未知并恢复可重试状态。命令只在当前页面内存中保留，避免把个人目标内容额外写入共用设备存储。刷新页面从服务端读取最新状态并进行幂等刷新，不自动重建或重放旧操作。 |
| 任务操作能力 | UI 自行重复判断；与领域命令共同判断 | 使用与服务端共享的只读校验 `taskCapabilities`／`commandCapability`，不克隆整个成长历史、不复制另一套规则；按能力区分编辑、完成、撤销、清单执行和重新安排。未来可改清单内容但不能提前勾执行；暂停当天已完成任务是否可撤销，也采用同一领域规则。 |
| 重复规则预览 | 只数未来 31 天任务；直接拼接规则；复用实际规则变更语义 | 采用 `forecastCycleChange` 的纯克隆预测：排除撤下／旧槽位，展示前后执行日期及首个受影响同一任务月的计划、实际、完成率和奖励。跨当前月生效时展示真正受影响月份；预览不提交数据，正式奖励由服务端计算。尚未开始的周期，生效日默认不早于开始日期。 |
| 已达成支线转换 | 完成后禁止转换；允许未归档目标转换 | 采用后者，保留同一目标、继续周期、任务月与长期积累；原目标冻结奖励和已结算快照不重算。归档内容仍只读，转换来源不可恢复。此项由主 agent 冻结默认并由领域代理实现。 |
| 归档确认 | 通用确认；列影响范围 | 展示全部关联目标与周期、所有未来一次性安排、31 天周期示例以及待结算行动／目标／完整任务月。周期未来无限排期不展开成无限列表，明确示例范围，不能以窗口内数量冒充总量。 |
| 小屏组织 | 隐藏焦点；保留全部能力并重新排布 | 390px 下先展示行动、后展示焦点；成就横排可横向滚动，保留全部成就入口。弹窗支持 Escape、Tab 焦点约束、详情返回及触发点恢复。 |
| 达成后单独归档 | 随编辑入口一起隐藏；独立检查归档能力 | 完成目标不再允许编辑／重复达成，但仍按服务端共享校验提供单独归档；归档后不提供编辑、重复归档或撤销达成，主线其他目标继续。 |
| 系数展示 | 将累计系数直接叫适用系数；根据当前状态回推历史；保存并分别展示 | `multiplier` 表示累计值，`appliedMultiplier` 表示本期真实适用值。当前月、预测和账本采用同一展示；旧记录缺实际字段时明确未知，保留原公式，不猜测或重写历史。列表也显示领域给出的精确累计值，不自行复利或四舍五入。 |
| 零 XP 成就反馈 | 仅经验大于零提示；经验或新成就任一变化均提示 | 采用后者，零 XP 合法目标解锁成就时明确“未增加经验”并提示新成就；经验、等级和奖励金额保持服务端原值。 |
| 格式工具 | 新增运行时依赖；临时固定版本格式化 | 使用临时 `prettier@3.6.2`，沿用单引号、无分号，不改项目运行时依赖或 lock。 |

测试边界：浏览器回归使用真实鉴权函数、冒险 HTTP handler、领域命令和 CAS 适配器；只替换外部 Auth／PostgREST 与时间输入。真实 Supabase 权限、持久化和生产验收由交付总验收单独记录，不能由这些夹具替代。
