## 前端职责边界

业务规则只有一份，由后端权威判定。前端处理展示、交互级边界判断、输入格式校验和文案拼接；所有修改提交稳定 ID 与用户输入，不从文案推导业务含义。

| 前端负责 | 后端负责并返回结果 |
|---|---|
| 页签、筛选输入、弹窗、表单值、焦点和提交中状态 | 当前业务事实、状态及其可操作性 |
| 必填／空值、输入格式、字段长度及接口声明的输入约束提示 | 日期是否合法、历史是否冻结、归属与配额、终态和删除资格等业务校验 |
| 根据后端操作能力显示、禁用入口，并展示原因 | 完成、取消、达成、结束、改期、迁移、聚焦及排序是否允许 |
| 格式化日期、经验、数量，将服务端名称拼成归属路径和说明 | 规划日期、任务范围、排序、统计、进度及历史快照 |
| 展示奖励预览、当前等级、成就和操作反馈 | 计奖行动数、奖励金额、总经验、等级、本级进度、成就条件及差额 |
| 展示错误、保留未知结果的原请求，按版本应用响应 | 账户授权、事务、幂等、版本冲突及稳定命令结果 |

- 前端不复制业务判定算法，不调用共享领域命令在浏览器重新判断合法性；现有代码中的前端共享校验需在后续实现时按本设计调整，本次不修改。
- 不用浏览器本地日期自行判断可完成日，不自行统计列表推算经验／进度，不计算奖励、等级、成就或聚焦名额。日期和计数的展示格式不构成业务规则。
- 文案可以拼接“主线名 / 目标名”“已完成数 / 总数”等展示文本，但操作仍使用稳定 ID；不通过名称、层级字符串或按钮文字反解析归属与命令。
- 前端可持有最新响应以渲染页面，但不维护第二份权威业务状态；成功后应用服务端结果，不先自行完成奖励入账或终态传播。
- 能力是特定状态版本的展示依据，不是授权凭证。按钮可用也不能跳过后端提交校验；能力缺失或数据尚未加载时不自行猜测可操作。

## 接口需要提供的能力

以下是接口设计的语义需求，不是最终字段名、端点或数据结构。`capabilities` 表达操作能力，`reason` 表达不可操作原因；具体形式在接口定义阶段确定。

| 对象／场景 | 前端需要的接口内容 |
|---|---|
| 页面基础数据 | 服务端规划日期、状态版本、稳定 ID、用于展示的名称／状态／历史快照、已计算的统计和进度。 |
| 任务 | 编辑、完成、取消完成、改期、迁移、结束和误建删除的能力及原因；可编辑字段、合法日期范围与候选归属。 |
| 目标 | 编辑、聚焦／取消聚焦、排序、迁移、达成和结束的能力及原因；候选目的位置、允许的落位或调整方向。 |
| 主线 | 创建、改名和结束的能力及原因；独立身份与普通主线的展示区分，不由前端推导系统特殊身份。 |
| 有输入的操作 | 迁移等候选位置的允许情况和原因；服务端仍按最终输入重新校验，不能仅凭对象级“允许迁移”认定所有目的都合法。 |
| 目标达成预览 | 完成标准、历史有效计奖行动数、成就感选项、最终奖励、将停止的任务、不可撤销提示和对应版本。 |
| 系数切换 | 后端提供每档奖励预览，或选择变化后向后端请求预览，具体方式留接口设计决定；前端不计算 N×系数或零行动保底。 |
| 取消／结束／删除确认 | 受影响对象、奖励及成长变化预览、是否需要确认、确认提示；前端不自行判断经验或成就是否回退。 |
| 成长与流水 | 总经验、等级、本级进度、距升级经验、七个里程碑的满足情况／进度／差额、有效流水及来源；分页统计口径一致。 |
| 命令结果 | 最新状态版本及页面所需更新结果、稳定操作结果和可展示错误；结果应保持事实、奖励及实时成长投影的一致性。 |

日期、归属或配额等规则变化会使能力过期。对象级能力、输入约束和确认预览均不能替代最终业务校验；接口应清楚区分不可操作、输入错误、版本冲突和结果未知。

## 交互与失败处理

- 完成任务：入口依据后端能力，点击后禁用重复提交；成功后展示服务端给出的任务结果、经验及新满足的成就反馈，不在前端增加经验。
- 取消完成：依接口给出的确认要求及影响展示弹窗；确认后提交具体完成记录，成功后应用最新任务、奖励和成长结果，不在前端计算扣减。
- 目标达成：展示服务端预览，用户选择评价及填写可选感想，确认后提交；版本变化先重新读取并确认，不能静默改变奖励金额或自动重放达成。
- 迁移、结束和删除：使用接口候选、能力及影响；失败保持原界面事实，成功后按返回结果重新展示归属、顺序或只读状态。
- 409：读取最新数据，更新能力，提示用户重新确认原操作；不自动覆盖或重放旧意图。
- 网络超时／未知结果：最多等待 15 秒，保留内存中的原 requestId、expectedVersion 和 command，允许显式安全重试，不创建新请求身份。刷新后读取服务端，不重建旧操作。
- 账户切换：立即卸载旧账户页面、撤销旧请求，重新验证账户范围；旧表单不能以新账户身份提交。个人命令不持久化到共用设备。
- 弹窗支持 Escape、Tab 焦点约束及关闭后恢复焦点；加载中、失败和空列表分别展示，文案保持简短中文。

## 验收与待定边界

前端验收需同时检查 A 的桌面／手机布局和上述操作流程；后端返回不同能力或原因时，界面应正确显隐、禁用及提示。重点核对前端没有自行计算业务结果、解析名称充当 ID、重放冲突命令或对失效能力兜底放行。原型内存交互和旧浏览器报告不证明正式接口集成通过。

尚待确认：任务汇总范围与进度分母、已结束任务统计口径；终态显示开关粒度及持久化、终态排序、独立任务聚焦筛选口径。具体能力字段名、错误结构、预览及响应形式由接口定义阶段确定。本次不实现原型晋升、业务接口或数据库变更。
