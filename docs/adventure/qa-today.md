## 原型验收反馈修正

用户指出正式今日模块与已确认 A 原型不一致。`6cf6a42` 的功能／CI 通过没有覆盖逐项原型对照，不能支持“界面已完成”的结论；PR #146 已恢复草稿。以下历史验证仍有效，但不替代本轮视觉复验和用户正式验收。

复现：同一 Chromium 分别打开保留的 A 原型和正式构建，桌面1440px／手机390px反复验证，收起待完成行的编辑按钮为原型1、正式0，约1.5秒稳定失败。移除样式后仍缺按钮，证明结构未迁入；CSSOM 检查又确认旧通用 Record 和页面按钮规则覆盖了字体及控件。搜索框、短日期和内边距还存在本地数值漂移。手机搜索宽度的一部分差异来自既有全站侧栏，用相同796px／300px模块宽度排除后再比较。

修正范围：

- 恢复独立完成／撤销圆钮、行内编辑和独立详情箭头；展开只显示说明，取消完成仍走已有预览确认。
- 恢复分组数量（整个搜索结果内的数量，跨20条分页保持一致）、月日格式和完整日期提示、周历“今天”小标。
- 今日组件使用独立样式，恢复字体、颜色、行高、控件尺寸、边框、内边距、搜索框、分隔线和5px进度轨道；删除入口回到表单左侧红字。
- 保留全站导航、主题背景、公共字体、成长区，以及正式删除／撤销预览内容。原型的演示切换器不迁入产品；日期弹窗内部对照一致，不重复修改。

新增 `tests/browser/adventure-today-parity.spec.ts`，通过现有浏览器入口验证真实页面与样式，先在两个视口均因缺编辑入口失败，再验证修复后的控件、日期、字重、间距及焦点恢复。真实业务继续由现有数据库浏览器套件验证；旧 ISO 文本／重复状态段落断言改为短日期的完整日期提示和可用／禁用控件，不放宽持久化、奖励、历史或并发断言。

修复后同宽样式对照通过，独立审计复核展开行尺寸、表单、过去／未来边界及26条分页的分组总数。最终整轮和控件尺寸复验结果在本轮收尾时补充；当前记录不提前声明全部验证完成。

## 复现环境

使用 Node 24.22.1、隔离 PostgreSQL 17／PostgREST、系统 Chromium。正式业务经浏览器／Worker／数据库执行，仅身份与 RPC 目的地受控；历史数据通过仅测试安装的历史 seed 构造，生产没有模拟日期接口。各工作区使用独立端口与依赖缓存，同工作区的浏览器服务器顺序运行。

系统 `/tmp` 空间不足时使用磁盘临时目录；安全夹具不能位于被项目安全规则禁止读取的 `.cache` 路径。相关环境失败已定位后重跑，没有放宽安全断言或排除业务测试。
