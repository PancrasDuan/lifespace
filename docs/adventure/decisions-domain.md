# 领域规则与实现约束

状态：2026-10-20 已同步本轮目标领域结论，待实现；以 [规格](spec.md) 为准，旧验证不构成本版通过证据。奖励机制留待后续讨论。

| 边界 | 当前选择 |
|---|---|
| 承载 | 普通主线只挂目标，目标挂一次性／周期任务；系统独立区承载独立目标和独立任务，不占 5 条普通主线名额、不能结束。 |
| 创建与编辑 | 名称、完成标准必填，手动选择归属，不默认；进行中可修改，取消不保存，修改不触发达成。第一版无草稿、多阶段和目标删除。 |
| 生命周期 | 进行中、已达成终态、未达成而结束终态；仅目标手动确认或手动结束所属主线改变状态，空内容及下属全完成／结束／迁出不自动改变。 |
| 达成 | 按实际完成标准确认，无任务或有未完成任务均可；达成即终态，全部下属任务停止，不提供周期继续选择，需要继续的任务先迁出。 |
| 终态 | 不可撤销、恢复、修改、聚焦、迁移或新增任务，所有下属任务只读，即使当天也不可取消完成。上级结束不抹去已达成和已完成事实。 |
| 聚焦 | 仅进行中目标可聚焦，影响展示排序与任务筛选，不改变执行；每普通主线最多 3 个，独立目标共用 3 个，终态自动取消并释放名额。 |
| 排序 | 同一归属内聚焦在前、未聚焦在后，各组内部沿用手动顺序，排序不自动改变聚焦。 |
| 目标迁移 | 进行中可在独立区和在用普通主线间及跨主线迁移，身份不变、下属任务随行；保留聚焦前校验名额，满额先调整，成功追加目的同类组末尾，失败或取消不变。 |
| 任务迁移 | 任务可更换目标或转为独立任务，保留身份、周期与积累，不恢复终态任务，普通主线不直接接收。 |
| 历史归属 | 每次完成固定 taskId、mainlineId、goalId 与日期，独立任务 goalId 为空；迁移不改写过去归属，不把过去行动转计新目标，历史终态锁定不按当前归属绕过。 |
| 当天与历史 | 固定 Asia/Shanghai，过去执行记录冻结；仅当天且未被相关终态锁定的任务完成可取消，未来不可提前执行。 |
| 查看 | 终态目标默认隐藏、手动显示；详情及任务历史只读，已结束主线仍可进入查看目标。 |
| 奖励范围 | 取消任务完成不追加负数冲正；奖励记录删除、重算与到期结算细节后续讨论，不由终态只读推导未入账奖励处理。 |
| 任务停止 | 停止今天及未来未完成安排，不改写过去漏做、完成和历史事实。 |
| 周期与计划 | 规则今天或未来生效，历史不改写；暂停、任务月锚点、改期原槽位和额外完成的既有独立约束保留，不扩展奖励结算。 |

源与目的状态、必填字段、配额、聚焦、日期、幂等及终态锁定由服务端校验，不能只靠界面禁用。模块尚未上线，旧结构兼容不作为本期前置；本次不操作代码、本地数据或远端服务。
