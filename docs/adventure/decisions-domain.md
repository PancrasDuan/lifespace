# 领域实现补充选择

以下为正式开发中的可恢复默认；不覆盖已确认的奖励与只读规则。

| 边界 | 备选 | 当前选择与理由 |
|---|---|---|
| 暂停后当天纠错 | 先恢复周期才能撤销；允许纠错撤销 | 允许撤销当天已完成、未结算行动；暂停仍禁止追加完成和清单执行。纠错不等于恢复排期；结束、归档继续只读。 |
| 撤销已达成支线目标 | 无条件恢复；自动挤占或归档其他支线；恢复前校验名额 | 服务端重新校验 10 条在用支线，满额失败且全部状态不变，先释放名额再撤销。 |
| 已达成未归档支线迁移 | 一律禁止；允许保留同一目标迁移 | 允许升级新主线或迁入现有主线；原奖励冻结、账本和周期身份不变。主线配额及聚焦仍在同一命令原子校验，归档内容继续禁止迁移。 |
| 批量停止与过去记录 | 全部未完成记录标停止；只停止今天及未来 | 只改变今天及未来的未完成实例；过去漏做记录保持原状。周期生命周期停止后不再产生后续安排，历史奖励资格独立判断。 |
| 迟到访问自然结束 | 用截止日回写所有任务；区分实际截止与处理日期 | endedAt 表达业务截止，endedRecordedOn 表达服务端首次处理日；不因迟到处理把过去实例重新标停止，完整月奖励仍按截止日判断。 |
| 预约重复规则再编辑 | 叠加所有预约；替换新生效日之后的预约 | 保留新生效日前规则，替换其后预约，撤下版本留在 replacedRules，防重叠规则改变计划。已完成与过去槽保留。 |
| UI 操作能力 | 在组件重复校验；调用共享领域校验纯试算 | taskCapabilities／commandCapability 在隔离克隆上运行相同命令，提供是否可操作及理由；服务端仍再次校验，不信任浏览器结果。 |
| 修改重复规则预览 | 人工构造简化周期；复用正式 reducer 纯试算 | forecastCycleChange 复用正式命令并选择首个受影响任务月，同 index 比较前后计划、实际、完成率及奖励；不改变账户状态、不发送写入。 |
| 预览日期窗口 | 固定 28 天作为系统上限；任意窗口、默认短窗展示 | 共享排期支持任意明确日期范围；预览未传范围时展示生效日起 31 天，属于展示默认，不限制完整月分母、离线追赶或正式排期。 |
| 零计划完整月记录 | 不留任何月份证据；保留零奖励解释记录 | 保留月份记录，标明计划为零、完成率不适用、奖励为零、不增加达标月；不产生经验或额外行动。 |

正式领域状态从零开始；原型快照、模拟日期、演示经验不导入。普通版本与幂等 journal 属于 Worker 持久层，领域命令不接收 owner、XP、整包 state 或模拟结算日期。
