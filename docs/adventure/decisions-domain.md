# 人生冒险领域规则

状态：2026-10-20 本期只实现一次性任务，以下已确认、待实现和重新验收；本次只更新文档。有效需求以 [规格](spec.md) 为准。

| 边界 | 当前规则 |
|---|---|
| 承载 | 普通主线只挂目标；独立区承载独立目标和独立任务，固定且不能结束、不占 5 条普通主线名额。 |
| 目标 | 名称、完成标准必填，归属手选；进行中可改，只有手动确认达成／结束或所属主线手动结束改变状态；无目标删除、草稿或多阶段。 |
| 聚焦 | 仅进行中可聚焦，每普通主线最多 3 个、独立目标共用 3 个；仅排序和筛选，先聚焦、组内手动顺序，终态取消。 |
| 目标终态 | 已达成或未达成而结束；下属全部停止且只读，不可撤销、恢复、编辑、迁移或新增任务，已有完成成果保留。 |
| 任务类型 | 本期只有一次性任务，代表一次完整行动，创建后不可转换；不加入周期、暂停、额外完成、清单或计划结束日期。 |
| 任务内容 | 名称、执行日期、归属必填，说明可选；待完成时可编辑，历史快照不随当前修改。 |
| 任务状态 | 待完成、已完成、已结束；逾期仅为日期提示，漏做仍可重新安排；已完成不再变成未完成而结束。 |
| 日期 | 固定 Asia/Shanghai 服务端日期，仅当天安排可完成；过去冻结，未来不可提前完成；改期到今天或未来。 |
| 完成 | 同一行动仅一条有效完成，保存当时 taskId、mainlineId、goalId、日期、内容及来源快照。 |
| 取消完成 | 仅完成当天且未被任务／当前上级／历史归属终态锁定时允许；完成记录逻辑删除、界面移除、业务统计排除；重新完成不重复计数。 |
| 结束 | 待完成任务手动确认后立即停止且不可恢复；取消确认无变化，上级终态同样向下锁定，已完成事实不抹去。 |
| 误建删除 | 仅尚未开始、从未产生完成、奖励或历史安排的误建任务可逻辑删除；已开始、有记录、已完成、已结束不能删除，已取消记录也属于曾产生记录。 |
| 改期 | 保留任务与行动身份、原安排及来源关联；同一行动一个有效安排，不因改期重复完成或计奖。 |
| 迁移 | 进行中目标跨在用主线／独立区迁移、任务随行，保留聚焦先验名额、目的同类组末尾落位；任务可跨目标或独立身份迁移；失败／取消无部分变化。 |
| 历史归属 | 完成时归属固定，独立任务 goalId 为空；当前改名迁移不重写历史，原归属终态锁定不能被迁移绕过。 |
| 查看与进度 | 终态目标默认隐藏、可手动显示，只读详情与已结束主线入口保留；进度条展示有效完成，不设置达标比例，不自动达成目标。 |
| 奖励 | 完成记录逻辑删除已确定；奖励记录删除、结算与成长重算细节另议，不追加负数冲正。主线结束后未入账奖励停止，既有入账成果保留。 |

服务端统一校验归属、必填、配额、日期、有效完成唯一性、误建删除条件和终态锁定。汇总进度分母及已结束任务统计口径、终态显示开关与独立任务筛选口径尚待确认。
