# 外部 Agent 使用独立凭据访问个人账单

外部 Agent 通过专属 MCP 入口访问本人交易账户和创建普通流水。Agent 不持有网页的 Supabase 登录会话：Cloudflare Access 先验证 Service Token，Worker 再验证 Access 身份断言，查找服务端维护的凭据标识与用户绑定，并在线核对用户及当前准入白名单。未知或停用的绑定、无效身份及上游故障均拒绝访问。

此决定为 [ADR 0001](0001-supabase-auth.md) 的逐次会话验证增加一个范围明确的例外，仅适用于 Agent 入口。现有网页和业务 REST 接口仍按原规则验证 Supabase 登录会话；Agent 凭据不能用于这些接口。独立凭据不等同于网页会话，网页退出不会自动撤销它。

管理员在 Cloudflare 管理和发放 Service Token；数据库只保存凭据标识与用户的绑定，不保存 Client Secret。每次访问重新解析绑定，停用绑定后新的解析请求不再授权；已在途请求不自动回滚。同一用户可绑定多个凭据，单枚凭据只归属一个用户。

Agent 入口复用普通流水创建的校验与数据库事务，查询本人账户返回现有完整账户结果。Agent 被要求在对话中完整展示收支类型、金额、时间、账户、分类与备注，并在明确确认后提交；Worker 不读取外部对话，无法独立验证确认发生。

本决定选择手动发放的 Service Token，以支持少量用户的初期验证，避免先建设用户自助 OAuth 授权与凭据管理页面。Cloudflare 和目标 Agent 的实际兼容性、用户准入变化及凭据撤销边界仍须在发布前验收。

## #151：扩展独立登记退款工具

Agent 入口新增 `create_ledger_refund`，与普通流水创建保持独立。该扩展超出本文最初的普通流水范围，沿用既有 Agent 身份、绑定及在线准入，并直接复用网页退款服务和受控数据库事务；不将 Agent 凭据用于网页 REST。退款仍按 [ADR 0003](0003-ledger-refund-entries.md) 追加关联收入，固定继承父支出的账户和分类，保持原支出金额及既有余额、幂等与未知结果语义。

退款前的完整展示增加父支出关联及继承信息，字段改变后重新展示并取得明确确认。服务端只验证业务事实，不能独立证明外部对话已确认。此扩展不增加转账、删除或通用历史查询；父流水详情不足时由用户补充核对，不猜测关联。
