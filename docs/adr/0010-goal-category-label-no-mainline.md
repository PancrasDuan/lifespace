# 取消主线，目标保留可选分类标签

状态：2026-11-11 已确认，Issue #164、#168。实现与集成验证状态见 [集成验收](../adventure/qa-goal-integration.md)；生产迁移、合并和发布须另获授权。

## 决定

取消“主线”作为独立领域对象、页面栏目、管理入口、生命周期和分页单位。目标成为人生冒险的唯一主结构；每个目标最多保留一个可选的纯文本分类标签。

分类标签只用于标示目标主题：可以留空，允许多个目标同名，改名只影响当前目标，不联动其他目标。它不参与分组、排序、筛选、配额、权限、目标状态或任务生命周期判断。

目标列表改为单一列表，不再按分类或原归属分组。进行中目标仍优先，沿用现有目标手动排序；开启“显示终态”时，已达成和已结束目标按现有规则排在后面。目标分页不变。

目标的新建、变更、达成和结束逻辑不变；新建和变更不再选择主线归属，改为填写可选分类标签。目标身份和下属任务关系不因改标签而改变。任务逻辑不变，独立任务继续保留。

现有普通主线名称迁移为所属目标上的分类标签；原独立目标标签为空。全面删除主线，同时保留目标、任务、完成、达成、奖励和经验等其他数据；删除这些历史记录中的主线信息及纯主线操作历史。后续完成与达成事件按发生时目标的分类标签留下快照。旧完成及达成不补写分类标签；数据库迁移及公开接口依 #168 协调切换。

本决策取代 [ADR 0002](0002-adventure-owner-state.md) 中保留主线表及主线操作事件的要求；其他数据与事务规则仍需在后端设计中保持一致。

## 后果

- 不再需要主线栏、主线分页、空主线管理、主线改名、目标归属迁移和独立区展示。
- 目标列表不再按分类归类，分类标签只是目标卡与关系弹卡上的展示信息。
- 目标驱动完整生命周期和任务；一个目标仍可拥有多个任务，任务可继续不依附目标。
- 分类标签去掉首尾空白后非空时为 1–200 个字符；空字符串表示无标签。改名不回写历史。
- 这会触及目标创建、变更、持久化归属字段、历史快照和公开接口，属于需确认的变更；已获本地实施授权，合并及发布须取得具体授权。

具体规则见 [D32](../adventure/decisions.md)、[D33](../adventure/decisions.md)、[D34 和 D35](../adventure/decisions.md)。
