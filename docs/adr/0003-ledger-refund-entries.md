# 账单使用独立流水与追加退款

每条个人账单流水独立记录一笔收入或支出，创建后不提供编辑。退款另建收入流水，关联一条普通支出流水并在明细中独立展示；交易账户与分类沿用父流水，交易金额和时间记录本次退款事实。

收支方向只保留收入和支出，退款与普通收入同属收入。是否关联父支出用于识别退款，不额外维护第三种收支方向或独立退款标记。

支出金额为负，收入和退款金额为正。原支出金额始终保留，累计有效退款不超过原支出金额的绝对值，并且只影响原支出的交易状态。

这一模型保留原交易与每次退款各自的金额和发生时间。支出状态由关联的未删除退款推导，因此会随退款流水新增或删除变化，属于关联事实的变化。

流水删除采用逻辑删除，保留底层记录，使用者不可见且不能恢复。删除原支出时同时逻辑删除其全部退款流水；单独删除退款流水时保留原支出，按剩余退款重新计算状态。
