# 删除已退役的机器绑定表与解析函数

#204 / PR #207 已将 legacy MCP 固定为404，撤销旧凭据并删除两条绑定。用户随后明确要求删除空的 `agent_identity_bindings`，因此移除该表与只供旧通道使用的 `agent_resolve_owner(text)`，替代 [ADR 0015](0015-retire-legacy-mcp.md) 中保留空表/RPC的选择。保留历史创建迁移，使用新的前向迁移记录删除，避免新环境再次保留无调用者的旧入口。

生产先确认空表和全部引用、备份真实对象定义及权限，并验证限定对象恢复。迁移单事务、拒绝非空、检查字符串函数引用并使用 RESTRICT，依赖冲突整体回滚，不级联删除。OAuth表/函数、KV、既有连接、用户与账单保持原样；恢复空表也不能重新启用 legacy MCP。具体执行门禁见 [退役清单](../mcp-legacy-retirement.md#空表与-rpc-收尾)。
