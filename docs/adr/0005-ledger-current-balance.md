# 账户余额按当前金额增减，手工修正直接校正当前值

为保持本期账户系统简单，账户余额由使用者手工设定，允许负数；新增收支、退款及账户间转账影响当前余额，补录旧交易也采用同一规则，删除流水则撤销相应金额影响。转账的两侧流水同时新增或删除，见 [账户间转账使用两条关联流水](0006-ledger-linked-transfer-entries.md)。手工余额修正直接覆盖当时的账户金额，不改变原交易，也不计为收入或支出；保留余额修正记录，但不在界面展示。

余额修正不建立按交易时间划分的结算截止点。例如余额为 1,000 元，记支出 20 元后为 980 元，手工修正为 900 元，再删除此前的 20 元支出，余额变为 920 元。使用者已确认这一结果，因此后续实现应保持当前余额的增减语义，不将余额修正解释为此前流水不再影响余额。

账户修改只提交实际改变的字段，改名不顺带回写旧余额。提交余额修正时校验表单读取到的余额；若期间金额已变化，保留输入、返回最新余额并提示重新核对后再提交，避免过时表单意外覆盖新收支的结果。

账户余额范围为 −999,999,999.99 至 ＋999,999,999.99 元，允许零并最多保留两位小数，采用整数分处理。开户、手工修正或流水联动结果超限时，整次操作拒绝并回滚，不截断金额。
