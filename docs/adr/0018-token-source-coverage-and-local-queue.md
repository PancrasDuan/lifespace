# 来源覆盖证明与不可变队列分开保护本地历史

#213 延续 ADR 0016/0017：Node 24 原生 SQLite 事务保存最新主汇总、单调版本、不可变请求及扫描覆盖证明；独立 SQLite 写事务持有运行锁，由 OS 释放，避免按超时删除活进程锁。新授权代际只有经浏览器批准领取后才能替代旧队列，再把最新主汇总从版本 1 重传；任一普通失败都不丢弃未确认请求。

Tokscale 4.23.0 没有逐文件×日期的完整性证明，且删除来源会清理解析缓存。我们只额外流式检验 JSONL envelope 的有效性与北京时间日期，保存文件逻辑字节摘要/长度/日期，不提取 token、正文或事件数据库；精确副本/归档/压缩移动和原前缀保留可以证明旧来源仍覆盖，截断/改写/丢失则保留受影响日期，未知范围保守保护全部日期。不会用总量不下降推断完整；来源恢复后解冻。这个选择牺牲缺失日期的自动重算，避免不可逆地丢失可信历史，也避免复制完整日志。

应用专用身份固定为 `lsd1_` 加 SHA-256，输入为 UTF-8 `lifespace-token-device-v1\0<linux|macos>\0<canonical-id>`，Linux machine-id 为去空白小写 32 hex，macOS IOPlatformUUID 为去空白小写标准 UUID；无 BOM 或结尾换行。零值/无效/不可读不随机回退，重装/hostname 改名保持身份；克隆系统必须在浏览器核对重绑，采集器不能凭同一硬件标识区分克隆。原始 ID 不持久化或输出。

新增编号核对了前置 SHA `04566322` 和最新 main `6c218846`。main 新增了另一个 0016，前置的同号 Token ADR 在最终统一集成时需重编号/更新引用，本阶段不改写已验收前置历史。
