# 账户间转账使用两条关联流水

为沿用现有流水记录和明细呈现方式，一次本人账户间转账使用转出、转入两条互相关联的流水表示，分别记录两个账户的资金流向。转账不属于个人真实收入或支出，两条流水需要能够被识别为同一笔转账的两侧。

转账沿用现有收入、支出类型表示资金方向，在相应分类中增加转入、转出：转入流水为收入类型、转入分类及正金额；转出流水为支出类型、转出分类及负金额。

使用者一次选择两个不同的本人交易账户，填写一份金额、时间和可选备注，生成等额、方向相反的两条流水，两条一起保存成功。

转账的两侧流水可以删除，必须一起删除，并同时撤销两个账户对应的余额变化；不提供单侧删除。录入错误时采用删除整组后重新录入的方式修正，不要求额外记录反向转账用于纠错。

转账流水不开放退款；实际转回资金时另记反向转账。普通收支与退款继续沿用 [独立流水与追加退款](0003-ledger-refund-entries.md) 的规则。
