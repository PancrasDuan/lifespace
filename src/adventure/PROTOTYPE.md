# 人生冒险页面原型

目的：比较行动、长期规划和角色成长三种信息组织方式，作为需求讨论材料。

启动：`npm run prototype:adventure`，打开 `http://127.0.0.1:5186/prototype.html?variant=A`。

- A 冒险概览：角色摘要 → 当前焦点 → 今日行动与成就。
- B 主线地图：长期规划为主体，今日行动作为辅助区域。
- C 角色档案：角色与属性常驻，右侧推进任务与目标。

底部箭头或键盘左右键切换布局，URL 的 `variant` 支持 A、B、C。布局间保留内存状态，刷新重置。

可体验：切换概览／规划／成长，查看阶段说明，完成任务并评价成就感，暂停／激活目标，以及超过 3 个焦点时的限制提示。

全部为示例数据。导航仅呈现项目上下文，不跳转业务页面。新增、排序、重复事项调度、阶段结算、成就解锁和周期奖励未实现；支线示例属性暂归职业成长。人物称号、属性条尺度和页面名称为视觉示例，未作为正式规则确认。

原型独立运行，不连接账户或业务服务，不持久化数据。尚未选定布局；讨论结束后再记录结论与归档原型。
