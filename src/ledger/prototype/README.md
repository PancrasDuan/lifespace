# 个人账单 UI 原型

这是用于核对账单界面的临时原型（throwaway prototype），与正式应用入口分开运行。使用者已选定 A 表格方案，本轮进一步确认弹出卡片与日期浮窗交互。

## 启动

在项目根目录运行：

```bash
npm run prototype:ledger
```

打开 <http://127.0.0.1:5186/finance/prototype?variant=A>。

当前原型固定使用 A，去掉候选方案切换条：

- 查看、新建、登记退款使用居中弹出卡片。
- 删除使用紧凑的二次确认卡片。
- 点击“自定义”展开双日历浮窗，再次点击收回并丢弃本次草稿；左选开始、右选结束，本周、本月填充草稿，点击应用后生效。
- 取消、Escape 或外部点击同样丢弃草稿；再次展开恢复已应用的日期。手机浮窗不遮挡触发按钮。
- 已精简页面、详情和表单说明，保留必要字段、校验与删除警告。
- 交易时间数字保留原生分段编辑；输入框其余区域打开日历与时分秒选择，时间滚动到边界停止。
- 原型数据状态从顶部“数据状态”查看。

分类已实现为收入 6 项、支出 9 项的固定下拉单选，无法匹配时选择对应“其他”。初始不预选，切换收支方向后重新选择；退款以只读字段沿用父支出分类，不使用普通收入分类菜单。交易账户仍自由填写。

投资理财记录实际资金进出全额，充值仅记录向其他方充值；不添加“充值后消费一律跳过”的限制。转账与还款不在本次讨论范围内，见 `docs/ledger/requirements-draft.md`。

新建与退款表单直接取消、关闭、Escape 或点击遮罩均丢弃本次输入，不增加放弃确认或草稿暂存；取消退款及删除确认关闭卡片回到列表。保存成功沿用当前方案：回到全部时间、第一页，仍按交易时间排序，补录旧交易不会强行置顶。删除保留当前筛选与有效页码。

已加入输入上限：单笔金额绝对值最高 999,999,999.99 元，去除首尾空白后的交易账户最多 50 个 Unicode 码点，普通与退款备注最多 500 个码点；超限拒绝保存并保留输入，不截断文字。

## 数据与使用范围

展示内容全部是虚构的模拟数据。新建、退款和删除只影响当前页面内存，刷新页面即可重置；原型不连接数据库、鉴权或正式业务接口，也不写入浏览器持久存储。

正式功能还须在提交删除时重新核对关联退款范围，变化时更新提示并重新确认。当前内存原型不模拟其他设备写入，不作为此项并发验收的证据。

独立 Vite 入口仅在开发模式渲染原型。它不修改正式 LifeSpace 的路由，也不作为生产功能交付。用户选定布局后，再将验证过的设计转化为正式实现，并单独保留原型作为设计依据。
